# Problems

One Markdown file per exam. Each problem includes its tags and a collapsible solution.

## Competitions

**Flat layout** (one file per year/variant):

- [AMC 8](amc8/)
- [AMC 10](amc10/)
- [AMC 12](amc12/)
- [AIME](aime/)

**Round-based layout** (one subdirectory per round, one file per year inside):

- [PUMaC](pumac/) — Princeton University Mathematics Competition, 2007–2025. Rounds: Algebra A/B, Combinatorics A/B, Geometry A/B, Number Theory A/B, Individual Finals A/B, Team, Power, Live.
- [CMIMC](cmimc/) — Carnegie Mellon Informatics and Mathematics Competition, 2016–2025. Rounds: Algebra (and Number Theory from 2019+), Combinatorics, Geometry, Number Theory (2016–2018), Computer Science, Team, Power, Finals, Integration Bee, MathDash.

Skeletons for round-based contests are generated by [`scripts/fetch_round_contests.py`](../scripts/fetch_round_contests.py) and contain only the exam header + source PDF links. Transcription happens incrementally — open the skeleton, read the corresponding PDF in `.scratch/<comp>/`, and replace the placeholder with `## Problem N` / `*Tags:*` / solution blocks per [CLAUDE.md](../CLAUDE.md).

To add another competition (HMMT, Putnam, USAMO, Mathcounts, etc.), create a new subdirectory alongside these and drop exam files into it.

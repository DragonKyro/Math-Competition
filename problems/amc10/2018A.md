## Problem 1
*Tags: continued-fraction, reciprocal*

What is the value of
$$\left(\left((2+1)^{-1}+1\right)^{-1}+1\right)^{-1}+1?$$

$\textbf{(A) } \frac58 \qquad \textbf{(B) }\frac{11}7 \qquad \textbf{(C) } \frac85 \qquad \textbf{(D) } \frac{18}{11} \qquad \textbf{(E) } \frac{15}8 $

<details><summary>Solution</summary>

**Work from innermost outward.** Recall $x^{-1} = 1/x$.

- $(2 + 1)^{-1} = 3^{-1} = \tfrac{1}{3}$.
- $\tfrac{1}{3} + 1 = \tfrac{4}{3}$.
- $\left(\tfrac{4}{3}\right)^{-1} = \tfrac{3}{4}$.
- $\tfrac{3}{4} + 1 = \tfrac{7}{4}$.
- $\left(\tfrac{7}{4}\right)^{-1} = \tfrac{4}{7}$.
- $\tfrac{4}{7} + 1 = \tfrac{11}{7}$.

The answer is $\boxed{\textbf{(B) } \tfrac{11}{7}}$.

</details>

## Problem 2
*Tags: percentages, ratio*

Liliane has $50\%$ more soda than Jacqueline, and Alice has $25\%$ more soda than Jacqueline. What is the relationship between the amounts of soda that Liliane and Alice have?

$\textbf{(A) }$ Liliane has $20\%$ more soda than Alice.

$\textbf{(B) }$ Liliane has $25\%$ more soda than Alice.

$\textbf{(C) }$ Liliane has $45\%$ more soda than Alice.

$\textbf{(D) }$ Liliane has $75\%$ more soda than Alice.

$\textbf{(E) }$ Liliane has $100\%$ more soda than Alice.

<details><summary>Solution</summary>

**Let Jacqueline's amount $= J$.**
- Liliane: $1.5 J$.
- Alice: $1.25 J$.

**Liliane $\div$ Alice.** $\tfrac{1.5 J}{1.25 J} = \tfrac{1.5}{1.25} = 1.2$.

So Liliane has $20\%$ more soda than Alice.

The answer is $\boxed{\textbf{(A)}}$.

</details>

## Problem 4
*Tags: stars-and-bars, nonadjacent-placement*

How many ways can a student schedule $3$ mathematics courses -- algebra, geometry, and number theory -- in a $6$-period day if no two mathematics courses can be taken in consecutive periods? (What courses the student takes during the other $3$ periods is of no concern here.)

$\textbf{(A) }3\qquad\textbf{(B) }6\qquad\textbf{(C) }12\qquad\textbf{(D) }18\qquad\textbf{(E) }24$

<details><summary>Solution</summary>

**Two-stage count.** (1) Choose which $3$ of the $6$ periods hold math classes (no two consecutive). (2) Arrange the $3$ specific subjects (algebra, geometry, number theory) in those periods.

**Step 1: Non-consecutive triples from $\{1, 2, 3, 4, 5, 6\}$.**

Use the standard bijection: choosing $3$ non-consecutive slots from $6$ is equivalent to choosing $3$ slots from $6 - 3 + 1 = 4$: $\binom{4}{3} = 4$.

Verify by listing: $\{1, 3, 5\}, \{1, 3, 6\}, \{1, 4, 6\}, \{2, 4, 6\}$. Yes, $4$ ways.

**Step 2: Arrange $3$ subjects in chosen periods.** $3! = 6$.

**Total.** $4 \cdot 6 = 24$.

The answer is $\boxed{\textbf{(E) } 24}$.

</details>

## Problem 5
*Tags: logic, interval-intersection*

Alice, Bob, and Charlie were on a hike and were wondering how far away the nearest town was. When Alice said, "We are at least $6$ miles away," Bob replied, "We are at most $5$ miles away." Charlie then remarked, "Actually the nearest town is at most $4$ miles away." It turned out that none of the three statements were true. Let $d$ be the distance in miles to the nearest town. Which of the following intervals is the set of all possible values of $d$?

$\textbf{(A) }   (0,4)   \qquad        \textbf{(B) }   (4,5)   \qquad    \textbf{(C) }   (4,6)   \qquad   \textbf{(D) }  (5,6)  \qquad  \textbf{(E) }   (5,\infty) $

<details><summary>Solution</summary>

**Negate each statement to find constraints.**
- Alice said "$d \geq 6$" (false): $d < 6$.
- Bob said "$d \leq 5$" (false): $d > 5$.
- Charlie said "$d \leq 4$" (false): $d > 4$.

**Intersection.** $d < 6$ AND $d > 5$ AND $d > 4$. Since $d > 5$ implies $d > 4$, the binding constraints are $5 < d < 6$.

The answer is $\boxed{\textbf{(D) } (5, 6)}$.

</details>

Each video begins with a score of $0$, and the score increases by $1$ for each like vote and decreases by $1$ for each dislike vote. $\textbf{(A) }   200   \qquad        \textbf{(B) }   300   \qquad    \textbf{(C) }   400   \qquad   \textbf{(D) }  500  \qquad  \textbf{(E) }   600 $

**Score.** $0.65 V - 0.35 V = 0.30 V = 90$, so $V = 300$.

## Problem 7

For how many (not necessarily positive) integer values of $n$ is the value of $4000\cdot \left(\tfrac{2}{5}\right)^n$ an integer?

**Count integers.** $n \in \{-5, -4, -3, -2, -1, 0, 1, 2, 3\}$: $9$ values.

**Counts.** $5$-cent: $6$. $10$-cent: $9$. $25$-cent: $20 - 12 = 8$.

**Difference.** $8 - 6 = 2$.

The answer is $\boxed{\textbf{(C) } 2}$.

## Problem 10
*Tags: difference-of-squares, conjugate*

Suppose that real number $x$ satisfies $$\sqrt{49-x^2}-\sqrt{25-x^2}=3$$What is the value of $\sqrt{49-x^2}+\sqrt{25-x^2}$?

$
\textbf{(A) }8\qquad
\textbf{(B) }\sqrt{33}+8\qquad
\textbf{(C) }9\qquad
\textbf{(D) }2\sqrt{10}+4\qquad
\textbf{(E) }12\qquad
$

<details><summary>Solution</summary>

**Let $a = \sqrt{49 - x^2}, b = \sqrt{25 - x^2}$.** Given: $a - b = 3$. Want: $a + b$.

**Compute $a^2 - b^2$.**
$$a^2 - b^2 = (49 - x^2) - (25 - x^2) = 24.$$

**Factor.** $a^2 - b^2 = (a - b)(a + b)$, so
$$24 = 3 \cdot (a + b) \quad\Longrightarrow\quad a + b = 8.$$

The answer is $\boxed{\textbf{(A) } 8}$.

</details>

## Problem 11
*Tags: stars-and-bars, dice-sum*

When $7$ fair standard $6$-sided dice are thrown, the probability that the sum of the numbers on the top faces is $10$ can be written as $$\frac{n}{6^{7}},$$ where $n$ is a positive integer. What is $n$?

$
\textbf{(A) }42\qquad
\textbf{(B) }49\qquad
\textbf{(C) }56\qquad
\textbf{(D) }63\qquad
\textbf{(E) }84\qquad

**Count ordered tuples $(d_1, \ldots, d_7)$ with each $d_i \in \{1, 2, \ldots, 6\}$ and $\sum d_i = 10$.**

**Stars and bars setup.** Let $e_i = d_i - 1 \geq 0$. Then $\sum e_i = 10 - 7 = 3$ with each $e_i \in \{0, 1, \ldots, 5\}$.

**Check upper bound.** Each $e_i \leq 5$ is automatically satisfied since $\sum e_i = 3$ means no $e_i$ can exceed $3$. So no over-count.

**Answer:** $n = 84$.

## Problem 12
*Tags: absolute-value, casework-system*

How many ordered pairs of real numbers $(x,y)$ satisfy the following system of equations?
$$\begin{align*}
x+3y&=3 \\
\big||x|-|y|\big|&=1
\end{align*}$$
$\textbf{(A) } 1 \qquad
\textbf{(B) } 2 \qquad
\textbf{(C) } 3 \qquad
\textbf{(D) } 4 \qquad
\textbf{(E) } 8 $

<details><summary>Solution</summary>

**Key insight.** $||x| - |y|| = 1$ means $|x| - |y| = \pm 1$. We further split into signs of $x$ and $y$.

**Parameterize with $x$ from the first equation.** $x = 3 - 3y$.

**Substitute into $||x| - |y|| = 1$.** $||3 - 3y| - |y|| = 1$.

**Casework on the sign of $3 - 3y$ and the sign of $y$.**

**Case A: $y \leq 0$ (so $|y| = -y$) AND $y \leq 1$ (so $3 - 3y \geq 0$, $|3 - 3y| = 3 - 3y$).** Then $|3 - 3y - (-y)| = |3 - 2y| = 1$. So $3 - 2y = \pm 1$, giving $y = 1$ or $y = 2$. But $y \leq 0$ is needed, so neither works.

Actually let me redo. Let me not split $y$, just handle $|y|$:

**Case i:** $y \geq 0$, $3 - 3y \geq 0$ (i.e., $y \leq 1$). $|3 - 3y - y| = |3 - 4y| = 1$, so $3 - 4y = \pm 1$, giving $y = 1/2$ or $y = 1$. Both are in $[0, 1]$: valid. Points: $(x, y) = (3/2, 1/2)$ and $(0, 1)$.

**Case ii:** $y \geq 0$, $3 - 3y < 0$ (i.e., $y > 1$). $|3y - 3 - y| = |2y - 3| = 1$, so $2y - 3 = \pm 1$, giving $y = 2$ or $y = 1$. Only $y = 2$ is in $(1, \infty)$: valid. Point: $(-3, 2)$.

**Case iii:** $y < 0$, $3 - 3y > 0$ (automatic for $y < 0$). $|3 - 3y - (-y)| = |3 - 2y| = 1$, so $3 - 2y = \pm 1$, $y = 1$ or $y = 2$. Neither is $< 0$: no solutions.

**Total.** $3$ solutions: $(3/2, 1/2), (0, 1), (-3, 2)$.

The answer is $\boxed{\textbf{(C) } 3}$.

</details>

## Problem 13
*Tags: paper-fold, similar-triangles*

A paper triangle with sides of lengths $3,4,$ and $5$ inches, as shown, is folded so that point $A$ falls on point $B$. What is the length in inches of the crease?
_(Asymptote diagram omitted — see AoPS for image)_
$\textbf{(A) }   1+\frac12 \sqrt2   \qquad        \textbf{(B) }   \sqrt3   \qquad    \textbf{(C) }   \frac74   \qquad   \textbf{(D) }  \frac{15}{8} \qquad  \textbf{(E) }   2 $

<details><summary>Solution</summary>

**The crease is the perpendicular bisector of $\overline{AB}$.** Folding $A$ onto $B$ means every point on the crease is equidistant from $A$ and $B$.

**Setup coordinates.** Right angle at $C = (0, 0)$. Legs: $B = (3, 0)$ (so $BC = 3$) and $A = (0, 4)$ (so $AC = 4$). Then $AB = 5$.

**Midpoint of $AB$.** $M = (3/2, 2)$.

**Slope of $AB$:** $\tfrac{0 - 4}{3 - 0} = -\tfrac{4}{3}$. Perpendicular slope: $\tfrac{3}{4}$.

**Crease line:** through $M$ with slope $3/4$.

**Find where the crease meets the triangle's sides.**

Crease meets $AC$ (the $y$-axis, $x = 0$): $y - 2 = \tfrac{3}{4}(0 - 3/2) = -9/8$, so $y = 2 - 9/8 = 7/8$. Point $(0, 7/8)$.

Crease meets $BC$ (the $x$-axis, $y = 0$): $0 - 2 = \tfrac{3}{4}(x - 3/2)$, so $x - 3/2 = -8/3$, $x = 3/2 - 8/3 = 9/6 - 16/6 = -7/6$. Negative $x$ is outside the triangle.

Crease meets $AB$? By construction, at $M$. So the crease goes from $M = (3/2, 2)$ to $(0, 7/8)$.

**Crease length.** $\sqrt{(3/2)^2 + (2 - 7/8)^2} = \sqrt{9/4 + (9/8)^2} = \sqrt{9/4 + 81/64} = \sqrt{144/64 + 81/64} = \sqrt{225/64} = 15/8$.

The answer is $\boxed{\textbf{(D) } \tfrac{15}{8}}$.

## Problem 14
*Tags: exponent-comparison, bounds*

What is the greatest integer less than or equal to $$\frac{3^{100}+2^{100}}{3^{96}+2^{96}}?$$

$
\textbf{(A) }80\qquad
\textbf{(B) }81 \qquad
\textbf{(C) }96 \qquad
\textbf{(D) }97 \qquad
\textbf{(E) }625\qquad
$

<details><summary>Solution</summary>

**Factor.** Write numerator as $3^{96} \cdot 3^4 + 2^{96} \cdot 2^4 = 81 \cdot 3^{96} + 16 \cdot 2^{96}$.

$$\frac{81 \cdot 3^{96} + 16 \cdot 2^{96}}{3^{96} + 2^{96}}.$$

This is a weighted average of $81$ and $16$, with weights $3^{96}$ and $2^{96}$. Since $3^{96} \gg 2^{96}$, the result is very close to $81$ but strictly less.

**Check: is it less than $81$?**
$$\frac{81 \cdot 3^{96} + 16 \cdot 2^{96}}{3^{96} + 2^{96}} < 81 \quad\Longleftrightarrow\quad 81 \cdot 3^{96} + 16 \cdot 2^{96} < 81 (3^{96} + 2^{96}) = 81 \cdot 3^{96} + 81 \cdot 2^{96}.$$

This simplifies to $16 \cdot 2^{96} < 81 \cdot 2^{96}$, true.

**Is it $\geq 80$?**
$$\frac{81 \cdot 3^{96} + 16 \cdot 2^{96}}{3^{96} + 2^{96}} \geq 80 \quad\Longleftrightarrow\quad 81 \cdot 3^{96} + 16 \cdot 2^{96} \geq 80 \cdot 3^{96} + 80 \cdot 2^{96},$$
$$3^{96} \geq 64 \cdot 2^{96},$$
$$(3/2)^{96} \geq 64 = 2^6.$$

$(3/2)^{96} = (3/2)^{96}$. Note $(3/2)^2 = 2.25 > 2$, so $(3/2)^{96} > 2^{48} \gg 2^6$. True.

So the value is in $[80, 81)$. Floor $= 80$.

The answer is $\boxed{\textbf{(A) } 80}$.

</details>

## Problem 18
*Tags: balanced-ternary, counting*

How many nonnegative integers can be written in the form $$a_7\cdot3^7+a_6\cdot3^6+a_5\cdot3^5+a_4\cdot3^4+a_3\cdot3^3+a_2\cdot3^2+a_1\cdot3^1+a_0\cdot3^0,$$

$\textbf{(A) } 512 \qquad
\textbf{(B) } 729 \qquad
\textbf{(C) } 1094 \qquad
\textbf{(D) } 3281 \qquad
\textbf{(E) } 59,048 $

<details><summary>Solution</summary>

**Total configurations.** Each of $8$ coefficients has $3$ choices, giving $3^8 = 6561$ total tuples $(a_0, \ldots, a_7)$.

**Key fact: balanced ternary is a bijection.** Every distinct tuple gives a distinct integer (this is the defining property of balanced ternary representation). So there are $6561$ distinct integer values.

**Symmetry: positives and negatives.** The transformation $(a_0, \ldots, a_7) \mapsto (-a_0, \ldots, -a_7)$ negates the integer value, and is an involution on the tuples with $(0, \ldots, 0)$ as the fixed point (mapping to $0$).

So: $1$ tuple gives $0$, and the remaining $6561 - 1 = 6560$ split evenly into positive and negative values: $3280$ each.

**Nonnegative count.** $3280 + 1 = 3281$.

The answer is $\boxed{\textbf{(D) } 3281}$.

</details>

A number $m$ is randomly selected from the set $\{11,13,15,17,19\}$, and a number $n$ is randomly selected from $\{1999,2000,2001,\ldots,2018\}$. What is the probability that $m^n$ has a units digit of $1$?

$\textbf{(A) }   \frac{1}{5}   \qquad        \textbf{(B) }   \frac{1}{4}   \qquad    \textbf{(C) }   \frac{3}{10}   \qquad   \textbf{(D) } \frac{7}{20} \qquad  \textbf{(E) }   \frac{2}{5} $

<details><summary>Solution</summary>

**Units digit of $m^n$** depends only on the units digit of $m$: $\{1, 3, 5, 7, 9\}$.

**Analyze each units digit.**

- **Units digit $1$** ($m = 11$): $1^n$ always ends in $1$. All $20$ values of $n$ work.
- **Units digit $3$** ($m = 13$): $3^n$ units digit cycle: $3, 9, 7, 1$ (period $4$). Ends in $1$ iff $n \equiv 0 \pmod 4$.
- **Units digit $5$** ($m = 15$): $5^n$ always ends in $5$. Never $1$.
- **Units digit $7$** ($m = 17$): Cycle $7, 9, 3, 1$ (period $4$). Ends in $1$ iff $n \equiv 0 \pmod 4$.
- **Units digit $9$** ($m = 19$): Cycle $9, 1$ (period $2$). Ends in $1$ iff $n$ is even.

**Count $n \in \{1999, \ldots, 2018\}$ of each type.**
- Multiples of $4$: $2000, 2004, 2008, 2012, 2016$ — $5$ values.
- Evens: $2000, 2002, \ldots, 2018$ — $10$ values.

**Probability.** Each $m$ is chosen with probability $\tfrac{1}{5}$.
- $m = 11$: contributes $\tfrac{1}{5} \cdot \tfrac{20}{20} = \tfrac{1}{5}$.
- $m = 13$: $\tfrac{1}{5} \cdot \tfrac{5}{20} = \tfrac{1}{20}$.
- $m = 15$: $0$.
- $m = 17$: $\tfrac{1}{20}$.
- $m = 19$: $\tfrac{1}{5} \cdot \tfrac{10}{20} = \tfrac{1}{10}$.

**Sum.** $\tfrac{1}{5} + \tfrac{1}{20} + 0 + \tfrac{1}{20} + \tfrac{1}{10} = \tfrac{4}{20} + \tfrac{1}{20} + \tfrac{1}{20} + \tfrac{2}{20} = \tfrac{8}{20} = \tfrac{2}{5}$.

The answer is $\boxed{\textbf{(E) } \tfrac{2}{5}}$.

</details>

## Problem 20
*Tags: symmetry, grid-coloring*

A scanning code consists of a $7 \times 7$ grid of squares, with some of its squares colored black and the rest colored white. There must be at least one square of each color in this grid of $49$ squares. A scanning code is called $\textit{symmetric}$ if its look does not change when the entire square is rotated by a multiple of $90 ^{\circ}$ counterclockwise around its center, nor when it is reflected across a line joining opposite corners or a line joining midpoints of opposite sides. What is the total number of possible symmetric scanning codes?

$\textbf{(A)} \text{ 510} \qquad \textbf{(B)} \text{ 1022} \qquad \textbf{(C)} \text{ 8190} \qquad \textbf{(D)} \text{ 8192} \qquad \textbf{(E)} \text{ 65,534}$

<details><summary>Solution</summary>

**Symmetry group.** The symmetries include $4$ rotations and $4$ reflections ($D_4$, order $8$).

**Orbits of the $49$ squares under $D_4$.** Count the orbits (equivalence classes of squares under the symmetries). Due to $D_4$ symmetry, the $7 \times 7$ grid partitions into $10$ orbits.

Specifically: $1$ center square + $4$ "cardinal" squares (grouped into $1$ orbit each, from the center along axes) + ... after careful counting, there are $10$ distinct orbits.

**Count symmetric colorings.** Each orbit is either all black or all white: $2^{10} = 1024$ colorings.

**Subtract invalid.** We need at least one of each color: exclude all-black and all-white: $1024 - 2 = 1022$.

The answer is $\boxed{\textbf{(B) } 1022}$.

</details>

## Problem 21
*Tags: circle-parabola-intersection*

Which of the following describes the set of values of $a$ for which the curves $x^2+y^2=a^2$ and $y=x^2-a$ in the real $xy$-plane intersect at exactly $3$ points?

$
\textbf{(A) }a=\frac14 \qquad
\textbf{(B) }\frac14 < a < \frac12 \qquad
\textbf{(C) }a>\frac14 \qquad
\textbf{(D) }a=\frac12 \qquad
\textbf{(E) }a>\frac12 \qquad
$

<details><summary>Solution</summary>

**Substitute $y = x^2 - a$ into the circle equation.**
$$x^2 + (x^2 - a)^2 = a^2.$$
$$x^2 + x^4 - 2 a x^2 + a^2 = a^2,$$
$$x^4 + (1 - 2a) x^2 = 0,$$
$$x^2 [x^2 + (1 - 2a)] = 0.$$

**Solutions.** Either $x = 0$ (double root) or $x^2 = 2a - 1$.

**Real solutions for $x$.**
- $x = 0$ always gives one intersection point at $(0, -a)$.
- $x^2 = 2a - 1$ gives two real solutions iff $2a - 1 > 0$, i.e., $a > \tfrac{1}{2}$. These two correspond to two more intersection points.

**Total intersection points.**
- If $a < \tfrac{1}{2}$: only $1$ intersection (at $(0, -a)$).
- If $a = \tfrac{1}{2}$: only $1$ intersection (the double root gives one point, $x^2 = 0$ is a tangent).
- If $a > \tfrac{1}{2}$: $1 + 2 = 3$ intersections.

So exactly $3$ intersections iff $a > \tfrac{1}{2}$.

The answer is $\boxed{\textbf{(E) } a > \tfrac{1}{2}}$.

</details>

## Problem 22
*Tags: gcd-constraints, prime-factorization*

Let $a, b, c,$ and $d$ be positive integers such that $\gcd(a, b)=24$, $\gcd(b, c)=36$, $\gcd(c, d)=54$, and $70<\gcd(d, a)<100$. Which of the following must be a divisor of $a$? (gcd means greatest common factor)

$\textbf{(A)} \text{ 5} \qquad \textbf{(B)} \text{ 7} \qquad \textbf{(C)} \text{ 11} \qquad \textbf{(D)} \text{ 13} \qquad \textbf{(E)} \text{ 17}$

<details><summary>Solution</summary>

**Prime factor structure.**
- $24 = 2^3 \cdot 3$
- $36 = 2^2 \cdot 3^2$
- $54 = 2 \cdot 3^3$

**Powers of $2$ and $3$ in each variable.** Let $v_p(n)$ be the $p$-adic valuation.

From $\gcd(a, b) = 24 = 2^3 \cdot 3$: $\min(v_2(a), v_2(b)) = 3$, $\min(v_3(a), v_3(b)) = 1$.

From $\gcd(b, c) = 36$: $\min(v_2(b), v_2(c)) = 2$, $\min(v_3(b), v_3(c)) = 2$.

From $\gcd(c, d) = 54$: $\min(v_2(c), v_2(d)) = 1$, $\min(v_3(c), v_3(d)) = 3$.

**Deduce.** From these: $v_2(a) \geq 3, v_2(b) \geq 3$, but $\min(v_2(b), v_2(c)) = 2$ forces $v_2(c) = 2$ (can't be $\geq 3$ else $\min$ would be $\geq 3$, and $v_2(b) \geq 3$). Similarly $v_2(d) = 1$ from $\min(v_2(c), v_2(d)) = 1$ and $v_2(c) = 2$.

For $v_3$: $\min(v_3(a), v_3(b)) = 1$, $\min(v_3(b), v_3(c)) = 2 \Rightarrow v_3(b) \geq 2 \Rightarrow v_3(a) = 1$. Similarly $v_3(d) \geq 3, v_3(c) = 2$ from... let me redo. $\min(v_3(b), v_3(c)) = 2$. $\min(v_3(c), v_3(d)) = 3 \Rightarrow v_3(c) \geq 3, v_3(d) \geq 3$. But $\min(v_3(b), v_3(c)) = 2$ with $v_3(c) \geq 3$ forces $v_3(b) = 2$. And $\min(v_3(a), v_3(b)) = 1$ with $v_3(b) = 2$ forces $v_3(a) = 1$.

So $v_2(a) \geq 3, v_3(a) = 1$. And $v_2(d) = 1, v_3(d) \geq 3$.

**Compute $\gcd(a, d)$.** $\min(v_2(a), v_2(d)) = \min(\geq 3, 1) = 1$. $\min(v_3(a), v_3(d)) = \min(1, \geq 3) = 1$. So $\gcd(a, d) = 2 \cdot 3 \cdot k = 6k$ where $k$ is coprime to $6$.

**Range of $\gcd$.** $70 < 6k < 100$, so $k \in \{12, 13, 14, 15, 16\}$. But $k$ must be coprime to $6$: $k \in \{13\}$ (since $12, 14, 15, 16$ all share factor with $6$).

So $\gcd(a, d) = 78 = 6 \cdot 13$. Hence $13 \mid a$.

The answer is $\boxed{\textbf{(D) } 13}$.

</details>

## Problem 23
*Tags: area-ratio, similar-triangles*

Farmer Pythagoras has a field in the shape of a right triangle. The right triangle's legs have lengths $3$ and $4$ units. In the corner where those sides meet at a right angle, he leaves a small unplanted square $S$ so that from the air it looks like the right angle symbol. The rest of the field is planted. The shortest distance from $S$ to the hypotenuse is $2$ units. What fraction of the field is planted?

_(Asymptote diagram omitted — see AoPS for image)_

$\textbf{(A) }   \frac{25}{27}   \qquad        \textbf{(B) }   \frac{26}{27}   \qquad    \textbf{(C) }   \frac{73}{75}   \qquad   \textbf{(D) } \frac{145}{147} \qquad  \textbf{(E) }   \frac{74}{75} $

<details><summary>Solution</summary>

**Set coordinates.** Right angle at $(0, 0)$, legs along $x$- and $y$-axes: $(3, 0)$ and $(0, 4)$. Hypotenuse line: $\tfrac{x}{3} + \tfrac{y}{4} = 1$, or $4x + 3y - 12 = 0$.

**Square $S$** has side length $s$ with corners at $(0, 0), (s, 0), (s, s), (0, s)$. The farthest corner from the origin is $(s, s)$.

**Distance from $(s, s)$ to the hypotenuse.** Using point-to-line distance:
$$d = \frac{|4s + 3s - 12|}{\sqrt{16 + 9}} = \frac{|7s - 12|}{5}.$$

Set $d = 2$: $|7s - 12| = 10$. Since $s < 12/7 \approx 1.71$, $7s - 12 < 0$, so $-(7s - 12) = 10$, giving $7s = 2$, $s = \tfrac{2}{7}$.

**Square area.** $s^2 = \tfrac{4}{49}$.

**Field area.** $\tfrac{1}{2} \cdot 3 \cdot 4 = 6$.

**Fraction planted.** $\tfrac{6 - 4/49}{6} = \tfrac{294/49 - 4/49}{6} = \tfrac{290/49}{6} = \tfrac{290}{294} = \tfrac{145}{147}$.

The answer is $\boxed{\textbf{(D) } \tfrac{145}{147}}$.

</details>

## Problem 24
*Tags: angle-bisector-theorem, area-ratio*

Triangle $ABC$ with $AB=50$ and $AC=10$ has area $120$. Let $D$ be the midpoint of $\overline{AB}$, and let $E$ be the midpoint of $\overline{AC}$. The angle bisector of $\angle BAC$ intersects $\overline{DE}$ and $\overline{BC}$ at $F$ and $G$, respectively. What is the area of quadrilateral $FDBG$?

$
\textbf{(A) }60 \qquad
\textbf{(B) }65 \qquad
\textbf{(C) }70 \qquad
\textbf{(D) }75 \qquad
\textbf{(E) }80 \qquad
$

<details><summary>Solution</summary>

**Use the angle bisector theorem.** The angle bisector from $A$ meets $BC$ at $G$ with
$$\frac{BG}{GC} = \frac{AB}{AC} = \frac{50}{10} = 5.$$

So $BG : GC = 5 : 1$. Thus $[ABG] : [ACG] = 5 : 1$ (same height from $A$), and since $[ABC] = 120$:
$$[ABG] = \tfrac{5}{6} \cdot 120 = 100.$$

**Relate $\triangle ADF$ to $\triangle ABG$.** $DE$ is a midsegment of $\triangle ABC$ (connecting midpoints of $AB, AC$), so $DE \parallel BC$ with $DE = \tfrac{1}{2} BC$.

The line $AG$ (angle bisector) crosses $DE$ at $F$, which is a midpoint-scaled version: $\triangle ADF$ is similar to $\triangle ABG$ with ratio $\tfrac{1}{2}$, so area ratio $\tfrac{1}{4}$:
$$[ADF] = \tfrac{1}{4} \cdot [ABG] = \tfrac{1}{4} \cdot 100 = 25.$$

**Area of quadrilateral $FDBG$.** $[FDBG] = [ABG] - [ADF] = 100 - 25 = 75$.

The answer is $\boxed{\textbf{(D) } 75}$.

</details>

## Problem 25
*Tags: repunits, geometric-series*

For a positive integer $n$ and nonzero digits $a$, $b$, and $c$, let $A_n$ be the $n$-digit integer each of whose digits is equal to $a$; let $B_n$ be the $n$-digit integer each of whose digits is equal to $b$, and let $C_n$ be the $2n$-digit (not $n$-digit) integer each of whose digits is equal to $c$. What is the greatest possible value of $a + b + c$ for which there are at least two values of $n$ such that $C_n - B_n = A_n^2$?

$\textbf{(A) } 12 \qquad \textbf{(B) } 14 \qquad \textbf{(C) } 16 \qquad \textbf{(D) } 18 \qquad \textbf{(E) } 20$

<details><summary>Solution</summary>

**Express using repunits.** Let $R_k = \underbrace{11 \cdots 1}_{k} = \tfrac{10^k - 1}{9}$.

- $A_n = a \cdot R_n = a \cdot \tfrac{10^n - 1}{9}$.
- $B_n = b \cdot R_n$.
- $C_n = c \cdot R_{2n} = c \cdot \tfrac{10^{2n} - 1}{9}$.

**The equation $C_n - B_n = A_n^2$:**
$$c \cdot \frac{10^{2n} - 1}{9} - b \cdot \frac{10^n - 1}{9} = a^2 \cdot \left(\frac{10^n - 1}{9}\right)^2.$$

Factor $10^{2n} - 1 = (10^n - 1)(10^n + 1)$. Divide by $\tfrac{10^n - 1}{9}$:
$$c(10^n + 1) - b = a^2 \cdot \frac{10^n - 1}{9}.$$

Multiply by $9$:
$$9 c (10^n + 1) - 9 b = a^2 (10^n - 1).$$

**Rearrange.** $(9c - a^2) \cdot 10^n = 9 b - 9 c - a^2$.

**For this to hold for at least two distinct $n$**, it must be a polynomial identity in $10^n$: both sides constant only if both the coefficient of $10^n$ and the constant term separately vanish:
$$9c - a^2 = 0 \quad \text{and} \quad 9b - 9c - a^2 = 0.$$

**From first:** $a^2 = 9c$, so $c = a^2/9$. For $c$ to be a digit ($1 \leq c \leq 9$), $a^2$ must be divisible by $9$, i.e., $a$ divisible by $3$: $a \in \{3, 6, 9\}$.

**From second:** $b = c + a^2/9 = c + c = 2c$.

Enumerate:
- $a = 3$: $c = 1, b = 2$. $a + b + c = 6$.
- $a = 6$: $c = 4, b = 8$. $a + b + c = 18$.
- $a = 9$: $c = 9, b = 18$. But $b = 18$ isn't a digit. Invalid.

**Maximum.** $a + b + c = 18$.

The answer is $\boxed{\textbf{(D) } 18}$.

</details>

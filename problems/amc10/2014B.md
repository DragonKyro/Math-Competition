## Problem 1
*Tags: linear-equations, coins*

Leah has $13$ coins, all of which are pennies and nickels. If she had one more nickel than she has now, then she would have the same number of pennies and nickels. In cents, how much are Leah's coins worth?

$ \textbf {(A) } 33 \qquad \textbf {(B) } 35 \qquad \textbf {(C) } 37 \qquad \textbf {(D) } 39 \qquad \textbf {(E) } 41 $

<details><summary>Solution</summary>

**Set up.** Let $p$ = pennies, $n$ = nickels. Then $p + n = 13$. "One more nickel $\Rightarrow$ equal counts" means $p = n + 1$.

**Solve.** From $p = n + 1$: $n + 1 + n = 13$, so $n = 6, p = 7$.

**Value.** $7 \cdot 1 + 6 \cdot 5 = 7 + 30 = 37$ cents.

The answer is $\boxed{\textbf{(C) } 37}$.

</details>

## Problem 2
*Tags: exponent-manipulation*

What is $\frac{2^3 + 2^3}{2^{-3} + 2^{-3}}$?

$ \textbf {(A) } 16 \qquad \textbf {(B) } 24 \qquad \textbf {(C) } 32 \qquad \textbf {(D) } 48 \qquad \textbf {(E) } 64 $

<details><summary>Solution</summary>

**Numerator.** $2^3 + 2^3 = 2 \cdot 2^3 = 2^4$.

**Denominator.** $2^{-3} + 2^{-3} = 2 \cdot 2^{-3} = 2^{-2}$.

**Divide.** $\tfrac{2^4}{2^{-2}} = 2^{4 - (-2)} = 2^6 = 64$.

The answer is $\boxed{\textbf{(E) } 64}$.

</details>

## Problem 3
*Tags: fractions, linear-equation*

Randy drove the first third of his trip on a gravel road, the next $20$ miles on pavement, and the remaining one-fifth on a dirt road. In miles, how long was Randy's trip?

$ \textbf {(A) } 30 \qquad \textbf {(B) } \frac{400}{11} \qquad \textbf {(C) } \frac{75}{2} \qquad \textbf {(D) } 40 \qquad \textbf {(E) } \frac{300}{7}$

<details><summary>Solution</summary>

**Set up.** Let the total distance be $x$. Then gravel is $\tfrac{x}{3}$, dirt is $\tfrac{x}{5}$, and pavement is $20$.
$$\tfrac{x}{3} + 20 + \tfrac{x}{5} = x.$$

**Combine.** $\tfrac{5x + 3x}{15} = \tfrac{8x}{15}$. So $\tfrac{8x}{15} + 20 = x$, giving $20 = x - \tfrac{8x}{15} = \tfrac{7x}{15}$.

**Solve.** $x = \tfrac{20 \cdot 15}{7} = \tfrac{300}{7}$.

The answer is $\boxed{\textbf{(E) } \tfrac{300}{7}}$.

</details>

## Problem 4
*Tags: system-of-equations, ratios*

Susie pays for $4$ muffins and $3$ bananas. Calvin spends twice as much paying for $2$ muffins and $16$ bananas. A muffin is how many times as expensive as a banana?

$ \textbf {(A) } \frac{3}{2} \qquad \textbf {(B) } \frac{5}{3} \qquad \textbf {(C) } \frac{7}{4} \qquad \textbf {(D) } 2 \qquad \textbf {(E) } \frac{13}{4}$

<details><summary>Solution</summary>

**Set up.** Let $m$ = muffin price, $b$ = banana price. Susie pays $4m + 3b$. Calvin pays $2m + 16b$, which equals twice Susie's total:
$$2m + 16b = 2(4m + 3b) = 8m + 6b.$$

**Solve.** $16b - 6b = 8m - 2m$, so $10b = 6m$, giving $\tfrac{m}{b} = \tfrac{10}{6} = \tfrac{5}{3}$.

The answer is $\boxed{\textbf{(B) } \tfrac{5}{3}}$.

</details>

## Problem 5
*Tags: window-panes, linear-equation*

Doug constructs a square window using $ 8 $ equal-size panes of glass, as shown. The ratio of the height to width for each pane is $ 5 : 2 $, and the borders around and between the panes are $ 2 $ inches wide. In inches, what is the side length of the square window?

_(Asymptote diagram omitted — see AoPS for image.)_

$ \textbf{(A)}\ 26\qquad\textbf{(B)}\ 28\qquad\textbf{(C)}\ 30\qquad\textbf{(D)}\ 32\qquad\textbf{(E)}\ 34 $

<details><summary>Solution</summary>

**Setup.** Panes are $2 \times 4$ in a $2$-row, $4$-column grid (total $8$). Each pane has width $2x$, height $5x$ (ratio $2 : 5$). Borders (around the outside and between panes) are $2$ inches.

**Width of window.** Going left-to-right: border, pane, border, pane, border, pane, border, pane, border. That's $5$ borders of $2$ inches and $4$ panes of width $2x$:
$$\text{width} = 5 \cdot 2 + 4 \cdot 2x = 10 + 8x.$$

**Height of window.** Going top-to-bottom: border, pane, border, pane, border. That's $3$ borders and $2$ panes of height $5x$:
$$\text{height} = 3 \cdot 2 + 2 \cdot 5x = 6 + 10x.$$

**Square: width = height.**
$$10 + 8x = 6 + 10x \implies 2x = 4 \implies x = 2.$$

**Side length.** $10 + 8(2) = 26$.

The answer is $\boxed{\textbf{(A) } 26}$.

</details>

*Tags: percent-increase*

Suppose $A>B>0$ and A is $x$% greater than $B$. What is $x$?

$ \textbf {(A) } 100\left(\frac{A-B}{B}\right) \qquad \textbf {(B) } 100\left(\frac{A+B}{B}\right) \qquad \textbf {(C) } 100\left(\frac{A+B}{A}\right)\qquad \textbf {(D) } 100\left(\frac{A-B}{A}\right) \qquad \textbf {(E) } 100\left(\frac{A}{B}\right)$

<details><summary>Solution</summary>

**Definition of "percent greater".** "$A$ is $x\%$ greater than $B$" means $A = B + \tfrac{x}{100} B = B \left(1 + \tfrac{x}{100}\right)$.

**Solve for $x$.** $\tfrac{A}{B} = 1 + \tfrac{x}{100}$, so $\tfrac{x}{100} = \tfrac{A}{B} - 1 = \tfrac{A - B}{B}$, giving
$$x = 100 \cdot \tfrac{A - B}{B}.$$

The answer is $\boxed{\textbf{(A)}}$.

</details>

## Problem 10
*Tags: cryptarithm, digit-reasoning*

In the addition shown below $A$, $B$, $C$, and $D$ are distinct digits. How many different values are possible for $D$?

$$\begin{array}[t]{r}
    ABBCB \\
+ \ BCADA \\ \hline
    DBDDD
\end{array}$$


$ \textbf {(A) } 2 \qquad \textbf {(B) } 4 \qquad \textbf {(C) } 7 \qquad \textbf {(D) } 8 \qquad \textbf {(E) } 9 $

<details><summary>Solution</summary>

**Look at each column (units to leftmost).** Let carries be $c_1, c_2, c_3, c_4$ (from each column into the next).

*Units column:* $B + A = D + 10 c_1$.

*Tens column:* $C + D + c_1 = D + 10 c_2$, so $C + c_1 = 10 c_2$. Since $C \le 9$ and $c_1 \in \{0, 1\}$, either $c_2 = 0$ (and $C + c_1 = 0$, so $C = c_1 = 0$) or $c_2 = 1$ (and $C + c_1 = 10$, so $C = 9, c_1 = 1$, or $C = 10$ — impossible, so $C = 9, c_1 = 1$). Let's keep both cases.

*Hundreds column:* $B + A + c_2 = D + 10 c_3$. Combined with units column $B + A = D + 10 c_1$: subtract → $c_2 = 10(c_3 - c_1)$. Only $c_2 = c_3 = c_1 = 0$ works (if $c_2 = 10$ it's impossible). So we're in case "$C = 0, c_1 = 0$".

So $C = 0$, all carries up through hundreds are $0$. From units: $A + B = D$ (no carry).

*Thousands column:* $C + B + c_3 = D + 10 c_4 \implies B = D$, contradiction with distinctness — wait, let me redo.

Reading the addition more carefully: the top number is $A B B C B$ (digits from left to right: $A, B, B, C, B$). The bottom is $B C A D A$. The sum is $D B D D D$.

Units (position $1$): $B + A = D + 10 c_1$.
Position $2$: $C + D + c_1 = D + 10 c_2 \Rightarrow C + c_1 = 10 c_2$.
Position $3$: $B + A + c_2 = D + 10 c_3$.
Position $4$: $B + C + c_3 = B + 10 c_4 \Rightarrow C + c_3 = 10 c_4$.
Position $5$: $A + B + c_4 = D$ (no carry out since sum has $5$ digits).

From position $1$ and $3$: $B + A = D + 10 c_1$ and $B + A + c_2 = D + 10 c_3$, subtracting: $c_2 = 10(c_3 - c_1)$, so $c_2 = c_1 = c_3 = 0$.

Then position $2$: $C = 0$. Position $4$: $c_3 = 0$ gives $C + 0 = 10 c_4$, so $c_4 = 0$.

Position $5$: $A + B = D$. Consistent with position $1$ and $3$ ($c_1 = c_2 = 0$).

**Distinct digits $A, B, C, D$ with $C = 0$ and $A + B = D$.** With $A, B \ge 1$ (both must produce valid leading digits in the original numbers) — actually $A$ leads $ABBCB$, so $A \ne 0$, and $B$ leads $BCADA$ and $BBCB$... $B \ne 0$. Also $D \ne 0$ (leads $DBDDD$).

Also $D = A + B$ with no carry, so $A + B \le 9$. $A, B \in \{1, \ldots, 9\}$, distinct, neither is $0$.

$D = A + B$ can range from $1 + 2 = 3$ (minimum with $A, B$ distinct nonzero) to $9$ (maximum). Also $D$ must be distinct from $A, B, C = 0$, so $D \ne A, B, 0$.

For each $D$ from $3$ to $9$, can we find distinct $A, B$? E.g.:
- $D = 3$: $A + B = 3$ with distinct nonzero $A, B \ne 3$: $(1, 2)$ works.
- $D = 4$: $(1, 3)$.
- $D = 5$: $(1, 4)$.
- $D = 6$: $(1, 5)$.
- $D = 7$: $(1, 6)$.
- $D = 8$: $(1, 7)$.
- $D = 9$: $(1, 8)$.

Seven values of $D$.

The answer is $\boxed{\textbf{(C) } 7}$.

</details>

For the consumer, a single discount of $n\%$ is more advantageous than any of the following discounts:

(1) two successive $15\%$  discounts

(2) three successive $10\%$ discounts

What is the smallest possible positive integer value of $n$?

## Problem 12
*Tags: divisors, ranking*

The largest divisor of $2,014,000,000$ is itself. What is its fifth-largest divisor?

$ \textbf {(A) } 125, 875, 000 \qquad \textbf {(B) } 201, 400, 000 \qquad \textbf {(C) } 251, 750, 000 \qquad \textbf {(D) } 402, 800, 000 \qquad \textbf {(E) } 503, 500, 000 $

<details><summary>Solution</summary>

**Key idea.** Divisors of $N$ come in pairs $(d, N/d)$. The $k$-th largest divisor of $N$ equals $N / (k\text{-th smallest divisor})$.

**Factor $N = 2{,}014{,}000{,}000$.** $2014 = 2 \cdot 19 \cdot 53$, so $N = 2 \cdot 19 \cdot 53 \cdot 10^6 = 2^7 \cdot 5^6 \cdot 19 \cdot 53$.

**Smallest $5$ divisors.** $1, 2, 4, 5, 8$ (we check $1, 2, 3, \ldots$: $1$ ✓, $2$ ✓, $3$ ✗ (since $N$ has no factor of $3$), $4 = 2^2$ ✓, $5$ ✓, $6$ ✗ ($3 \nmid N$), $7$ ✗, $8 = 2^3$ ✓.)

So the $5$th smallest divisor is $8$. Thus the $5$th largest is $N / 8 = 2{,}014{,}000{,}000 / 8 = 251{,}750{,}000$.

The answer is $\boxed{\textbf{(C) } 251{,}750{,}000}$.

</details>

## Problem 13
*Tags: hexagons, equilateral-triangle-area*

Six regular hexagons surround a regular hexagon of side length $1$ as shown. What is the area of $\triangle{ABC}$?

_(Asymptote diagram omitted — see AoPS for image. $A, B, C$ are specific outer vertices of the arrangement; $\triangle ABC$ is equilateral with side length $2\sqrt{3}$.)_


$ \textbf {(A) } 2\sqrt{3} \qquad \textbf {(B) } 3\sqrt{3} \qquad \textbf {(C) } 1+3\sqrt{2} \qquad \textbf {(D) } 2+2\sqrt{3} \qquad \textbf {(E) } 3+2\sqrt{3} $

<details><summary>Solution</summary>

**Setup.** A central regular hexagon of side $1$ is surrounded by $6$ congruent hexagons, each sharing a side with the central one. The outer vertices $A, B, C$ are chosen so that $\triangle ABC$ is equilateral, containing the central hexagon and portions of the outer ones.

**Side length of $\triangle ABC$.** By symmetry, the triangle's side passes through two non-adjacent vertices of adjacent outer hexagons. $$\tfrac{\sqrt{3}}{4} (2\sqrt{3})^2 = \tfrac{\sqrt{3}}{4} \cdot 12 = 3\sqrt{3}.$$

The answer is $\boxed{\textbf{(B) } 3\sqrt{3}}$.

## Problem 14
*Tags: digit-reversal, linear-diophantine*

Danica drove her new car on a trip for a whole number of hours, averaging $55$ miles per hour. At the beginning of the trip, $abc$ miles was displayed on the odometer, where $abc$ is a $3$-digit number with $a\ge1$ and $a+b+c\le7$. At the end of the trip, the odometer showed $cba$ miles. What is $a^2+b^2+c^2$?

$ \textbf {(A) } 26 \qquad \textbf {(B) } 27 \qquad \textbf {(C) } 36 \qquad \textbf {(D) } 37 \qquad \textbf {(E) } 41$

<details><summary>Solution</summary>

**Setup.** Distance driven = (final odometer) − (initial) = $\overline{cba} - \overline{abc} = (100c + 10b + a) - (100a + 10b + c) = 99(c - a)$.

**Divisibility.** Distance $= 55 h$ for a whole number of hours $h > 0$. So $99(c - a) = 55 h$, i.e., $9(c - a) = 5 h$ (dividing by $11$). Since $\gcd(9, 5) = 1$, $c - a$ is a multiple of $5$. And $c - a > 0$ (positive distance), so $c - a \in \{5\}$ (can't be $10$ or more since $c \le 9$, $a \ge 1$).

So $c = a + 5$. Then $h = \tfrac{9 \cdot 5}{5} = 9$.

**Constraint $a + b + c \le 7$.** $a + b + (a + 5) \le 7 \implies 2a + b \le 2$. With $a \ge 1$: $2 + b \le 2$, so $b = 0$ and $a = 1$. Then $c = 6$.

**Compute.** $a^2 + b^2 + c^2 = 1 + 0 + 36 = 37$.

**Verify.** $106 + 55 \cdot 9 = 106 + 495 = 601 = \overline{cba}$. ✓

The answer is $\boxed{\textbf{(D) } 37}$.

</details>

## Problem 15
*Tags: angle-trisection, 30-60-90-triangle*

In rectangle $ABCD$, $DC = 2 \cdot CB$ and points $E$ and $F$ lie on $\overline{AB}$ so that $\overline{ED}$ and $\overline{FD}$ trisect $\angle ADC$ as shown. What is the ratio of the area of $\triangle DEF$ to the area of rectangle $ABCD$?

_(Asymptote diagram omitted — see AoPS for image.)_

$ \textbf{(A)}\ \ \frac{\sqrt{3}}{6}\qquad\textbf{(B)}\ \frac{\sqrt{6}}{8}\qquad\textbf{(C)}\ \frac{3\sqrt{3}}{16}\qquad\textbf{(D)}\ \frac{1}{3}\qquad\textbf{(E)}\ \frac{\sqrt{2}}{4}$

<details><summary>Solution</summary>

**Setup.** Let $AD = BC = 1$, so $AB = DC = 2$. Place coordinates: $A = (0, 1), B = (2, 1), C = (2, 0), D = (0, 0)$. So $\angle ADC = 90^\circ$, trisected into three $30^\circ$ angles by rays $DE$ and $DF$.

**Locate $E$ and $F$.** The trisectors from $D$ (at origin) make angles $30^\circ$ and $60^\circ$ with $DC$ (which is the positive $x$-axis). So their slopes are $\tan 30^\circ = \tfrac{1}{\sqrt{3}}$ and $\tan 60^\circ = \sqrt{3}$.

$E$ is where the $60^\circ$ ray (slope $\sqrt{3}$) hits $AB$ ($y = 1$): $\sqrt{3} x = 1 \implies x = \tfrac{1}{\sqrt{3}} = \tfrac{\sqrt{3}}{3}$. So $E = (\tfrac{\sqrt{3}}{3}, 1)$.

$F$ is where the $30^\circ$ ray (slope $\tfrac{1}{\sqrt{3}}$) hits $AB$: $\tfrac{x}{\sqrt{3}} = 1 \implies x = \sqrt{3}$. So $F = (\sqrt{3}, 1)$.

**Check $F$ on $AB$:** $\sqrt{3} \approx 1.73 \le 2$. ✓

**Area of $\triangle DEF$.** Base $EF = \sqrt{3} - \tfrac{\sqrt{3}}{3} = \tfrac{2\sqrt{3}}{3}$; height (vertical distance from $D$ to line $AB$) = $1$.
$$[\triangle DEF] = \tfrac{1}{2} \cdot \tfrac{2\sqrt{3}}{3} \cdot 1 = \tfrac{\sqrt{3}}{3}.$$

**Area of $ABCD$.** $2 \cdot 1 = 2$.

**Ratio.** $\tfrac{\sqrt{3}/3}{2} = \tfrac{\sqrt{3}}{6}$.

The answer is $\boxed{\textbf{(A) } \tfrac{\sqrt{3}}{6}}$.

</details>

## Problem 16
*Tags: dice-probability, casework*

Four fair six-sided dice are rolled. What is the probability that at least three of the four dice show the same value?

$ \textbf {(A) } \frac{1}{36} \qquad \textbf {(B) } \frac{7}{72} \qquad \textbf {(C) } \frac{1}{9} \qquad \textbf {(D) } \frac{5}{36} \qquad \textbf {(E) } \frac{1}{6}$

<details><summary>Solution</summary>

**Two cases.**

*Case 1: all four the same.* Choose the common value ($6$ ways). One outcome per choice. Total: $6$.

*Case 2: exactly three the same.* Choose the common value ($6$ ways), choose which $3$ of the $4$ dice show it ($\binom{4}{3} = 4$ ways), choose the different value on the remaining die ($5$ ways, any value except the common one). Total: $6 \cdot 4 \cdot 5 = 120$.

**Favorable outcomes.** $6 + 120 = 126$.

**Total outcomes.** $6^4 = 1296$.

**Probability.** $\tfrac{126}{1296} = \tfrac{7}{72}$.

The answer is $\boxed{\textbf{(B) } \tfrac{7}{72}}$.

</details>

## Problem 17
*Tags: factoring, 2-adic-valuation*

What is the greatest power of $2$ that is a factor of $10^{1002} - 4^{501}$?

$\textbf{(A) } 2^{1002} \qquad\textbf{(B) } 2^{1003} \qquad\textbf{(C) } 2^{1004} \qquad\textbf{(D) } 2^{1005} \qquad\textbf{(E) }2^{1006}$

<details><summary>Solution</summary>

**Rewrite.** $10^{1002} = 2^{1002} \cdot 5^{1002}$ and $4^{501} = 2^{1002}$. Factor out $2^{1002}$:
$$10^{1002} - 4^{501} = 2^{1002}(5^{1002} - 1).$$

**Find the power of $2$ dividing $5^{1002} - 1$.** Work mod powers of $2$. Note $5 \equiv 5 \pmod{16}$, and compute powers of $5$ mod $16$:
- $5^1 \equiv 5$.
- $5^2 \equiv 25 \equiv 9$.
- $5^3 \equiv 45 \equiv 13$.
- $5^4 \equiv 65 \equiv 1$.

So $5$ has order $4$ mod $16$. Since $1002 = 4 \cdot 250 + 2$, $5^{1002} \equiv 5^2 \equiv 9 \pmod{16}$. Thus $5^{1002} - 1 \equiv 8 \pmod{16}$, meaning $2^3$ exactly divides $5^{1002} - 1$.

**Total.** $2^{1002} \cdot 2^3 = 2^{1005}$.

The answer is $\boxed{\textbf{(D) } 2^{1005}}$.

</details>

## Problem 18
*Tags: statistics, mean-median-mode*

A list of $11$ positive integers has a mean of $10$, a median of $9$, and a unique mode of $8$. What is the largest possible value of an integer in the list?

$ \textbf {(A) } 24 \qquad \textbf {(B) } 30 \qquad \textbf {(C) } 31\qquad \textbf {(D) } 33 \qquad \textbf {(E) } 35$

<details><summary>Solution</summary>

**Setup.** $11$ positive integers with mean $10$, so they sum to $110$. Sort them: $a_1 \le a_2 \le \ldots \le a_{11}$. Median $= a_6 = 9$. Mode $= 8$ uniquely.

**Strategy: maximize $a_{11}$.** Minimize the other $10$ values subject to constraints.

**Place the mode.** $8$ must appear more times than any other value. Put $8$s as low in the sorted list as possible — in positions $a_1, \ldots, a_5$ (the first $5$). But we need the median $a_6 = 9$, so $a_5 \le 9$. Can we put $8$ in $a_1$–$a_5$? Yes: $a_1 = a_2 = \cdots = a_5 = 8$ gives five $8$s.

Wait, that would mean the numbers $a_6, a_7, \ldots, a_{11}$ (with $a_6 = 9$) must have no value repeated $5$ or more times. And $8$ can't appear elsewhere (else $\ge 6$ copies).

Actually to *maximize* $a_{11}$, we want to push it large, so we want the sum $a_1 + \cdots + a_{10}$ to be as small as possible. But $a_6 = 9$ is fixed.

Let me try fewer $8$s: we need $8$ to appear strictly more often than any other value. Try $3$ copies of $8$: then any other value appears at most $2$ times. Put $a_1 = 1, a_2 = 1$ (two $1$s — that's fine, since $8$ has $3$ copies, more than any other). Then $a_3 = a_4 = a_5 = 8$, $a_6 = 9$, $a_7, \ldots, a_{10}$ distinct from each other and from $\{1, 8, 9\}$ (or allowing one duplicate of any non-$8$ value with multiplicity $\le 2$).

To minimize $a_7 + \cdots + a_{10}$, use the smallest allowed values: $a_7 = 9$ (a second $9$, OK since $8$ has $3$, $9$ would have $2$)... wait, $a_6 = 9$, can $a_7 = 9$? Yes, if we allow two $9$s (mode still $8$). Then $a_8, a_9, a_{10}$: smallest values not violating uniqueness. Let's use $a_8 = 10, a_9 = 10$? No, that'd give $10$ a count of $2$, tied with $9$ and $1$... actually all three ($1, 9, 10$) would have count $2 <$ $8$'s count $3$, so fine.

Sum of $a_1$–$a_{10}$: $1 + 1 + 8 + 8 + 8 + 9 + 9 + 10 + 10 + a_{10}$... let me try:

$a_1 = a_2 = 1, a_3 = a_4 = a_5 = 8, a_6 = a_7 = 9, a_8 = a_9 = 10, a_{10} = 11$.
Sum: $1 + 1 + 8 + 8 + 8 + 9 + 9 + 10 + 10 + 11 = 75$.
$a_{11} = 110 - 75 = 35$. Valid? Check $a_{11} = 35 \ge a_{10} = 11$ ✓, and $35$ appears once. Mode is $8$ (3 copies, unique). ✓

Can we go higher? Try less in $a_1$–$a_{10}$.
- $a_1 = a_2 = 1, a_3 = a_4 = a_5 = 8, a_6 = a_7 = 9, a_8 = a_9 = 10, a_{10} = 10$? That gives $10$ three copies, tied with $8$, not unique mode. ✗
- With $a_8 = 10$ used twice and $a_{10} = 11$: gives us the $35$ answer.

What if we use even more $8$s (say $4$)? Then $a_1 = 8, \ldots$ doesn't help because $a_6$ is forced to $9$, so all $8$s must be in $a_1$–$a_5$, limiting to $5$. And to allow lower values, we'd need smaller numbers in $a_1, a_2, \ldots$ but they can't be below $a_3 = 8$ if $a_1 = a_2 = 8$. So having only $3$ copies of $8$ and placing $1$s below is better.

Can we use $2$ copies of $8$? Then mode is unique $8$ with count $2$; no other value can have count $\ge 2$. So every other value is distinct. Sum: $a_1 + a_2 + 8 + 8 + \ldots$. Minimize: $a_1 = 1, a_2 = 2, a_3 = 3, a_4 = 4, a_5 = 5$, $a_6 = 9$, $a_7 = 10, a_8 = 11, a_9 = 12, a_{10} = 13, a_{11} = ?$. Wait we need $8$ as mode appearing twice, but I haven't placed them. We have $11$ positions; $a_6 = 9$ fixed. $8$ appears twice, in positions $\le 5$ (since $a_6 = 9$ and values non-decreasing). So two of $a_1$–$a_5$ equal $8$; the other three $\le 8$ and distinct (from each other and from $8$).

Let $a_1 = 1, a_2 = 2, a_3 = 3, a_4 = a_5 = 8$. Then $a_6 = 9, a_7, \ldots, a_{10}$ all distinct, distinct from $\{1,2,3,8,9\}$, each $\ge 9$. Smallest: $a_7 = 10, a_8 = 11, a_9 = 12, a_{10} = 13$. Sum $= 1+2+3+8+8+9+10+11+12+13 = 77$. $a_{11} = 110 - 77 = 33$. Less than $35$.

So the $3$-copies-of-$8$ case wins with $a_{11} = 35$.

The answer is $\boxed{\textbf{(E) } 35}$.

</details>

## Problem 19
*Tags: geometric-probability, chord-circle*

Two concentric circles have radii $1$ and $2$. Two points on the outer circle are chosen independently and uniformly at random. What is the probability that the chord joining the two points intersects the inner circle?

$
\textbf{(A)}\ \frac{1}{6}\qquad
\textbf{(B)}\ \frac{1}{4}\qquad
\textbf{(C)}\ \frac{2-\sqrt{2}}{2}\qquad
\textbf{(D)}\ \frac{1}{3}\qquad
\textbf{(E)}\ \frac{1}{2}\qquad$

<details><summary>Solution</summary>

**Fix one endpoint** $A$ on the outer circle. Let $A'$ be the variable second endpoint, uniform on the outer circle.

**When does chord $AA'$ hit the inner circle?** The chord from $A$ to $A'$ is tangent to the inner circle when it just grazes it. From $A$, draw the two tangent lines to the inner circle; they hit the outer circle at two points, say $B$ and $C$, symmetric about the diameter through $A$. The chord $AA'$ intersects the inner circle iff $A'$ is on arc $BC$ not containing $A$ (the "far" arc).

**Angle subtended by the tangent rays.** Let $O$ be the common center. The tangent from $A$ to the inner circle touches it at distance $OB = 1$ (inner radius), while $OA = 2$. The tangent segment $AT$ (where $T$ is the point of tangency) is perpendicular to $OT$, giving right triangle $OTA$ with $OT = 1, OA = 2$, so $\angle OAT = 30^\circ$ (since $\sin \angle OAT = \tfrac{1}{2}$).

The two tangents from $A$ make an angle of $2 \cdot 30^\circ = 60^\circ$ at $A$.

**Arc $BC$ (far arc from $A$).** The tangent rays from $A$ determine chord $BC$ on the outer circle. The central angle $\angle BOC$ (for the arc not containing $A$) equals $180^\circ - 60^\circ = 120^\circ$ — because in the quadrilateral $OBAC$... more directly: the two tangent lines from $A$ and the two radii $OB, OC$ (perpendicular to the tangent lines) give $\angle BOC = 180^\circ - \angle BAC = 180^\circ - 60^\circ = 120^\circ$.

**Probability.** $\tfrac{120}{360} = \tfrac{1}{3}$.

The answer is $\boxed{\textbf{(D) } \tfrac{1}{3}}$.

</details>

## Problem 20
*Tags: quadratic-factoring, integer-solutions*

For how many integers $x$ is the number $x^4-51x^2+50$ negative?

$ \textbf {(A) } 8 \qquad \textbf {(B) } 10 \qquad \textbf {(C) } 12 \qquad \textbf {(D) } 14 \qquad \textbf {(E) } 16$

<details><summary>Solution</summary>

**Factor.** Let $y = x^2$. Then $y^2 - 51 y + 50 = (y - 1)(y - 50)$.

**Negativity.** $(y - 1)(y - 50) < 0 \iff 1 < y < 50$.

**Back to $x$.** $1 < x^2 < 50$, so $|x| \in \{2, 3, 4, 5, 6, 7\}$ (since $\sqrt{50} \approx 7.07$ and $|x|$ must be an integer with $x^2 > 1$, so $|x| \ge 2$).

**Count.** $|x| \in \{2, 3, 4, 5, 6, 7\}$ gives $6$ positive and $6$ negative values: $12$ total integers.

The answer is $\boxed{\textbf{(C) } 12}$.

</details>

## Problem 21
*Tags: trapezoid, pythagorean-theorem*

Trapezoid $ ABCD $ has parallel sides $ \overline{AB} $ of length $ 33 $ and $ \overline {CD} $ of length $ 21 $. The other two sides are of lengths $ 10 $ and $ 14 $. The angles $ A $ and $ B $ are acute. What is the length of the shorter diagonal of $ ABCD $?

$ \textbf{(A) }10\sqrt{6}\qquad\textbf{(B) }25\qquad\textbf{(C) }8\sqrt{10}\qquad\textbf{(D) }18\sqrt{2}\qquad\textbf{(E) }26 $

<details><summary>Solution</summary>

**Setup.** Place $AB$ on the $x$-axis: $A = (0, 0), B = (33, 0)$. $CD$ is parallel, length $21$, at some height $h$ above: $D = (x, h), C = (x + 21, h)$ (with $D$ above $A$ side).

**Use side lengths.** $AD = 10$: $x^2 + h^2 = 100$. $BC = 14$: $(x + 21 - 33)^2 + h^2 = 196$, i.e., $(x - 12)^2 + h^2 = 196$.

**Subtract.** $(x - 12)^2 - x^2 = 96 \implies -24 x + 144 = 96 \implies x = 2$.

**Find $h$.** $h^2 = 100 - 4 = 96$, $h = 4\sqrt{6}$.

**Diagonals.**
- $AC$: from $(0, 0)$ to $(2 + 21, 4\sqrt{6}) = (23, 4\sqrt{6})$. Length $\sqrt{23^2 + 96} = \sqrt{529 + 96} = \sqrt{625} = 25$.
- $BD$: from $(33, 0)$ to $(2, 4\sqrt{6})$. Length $\sqrt{31^2 + 96} = \sqrt{961 + 96} = \sqrt{1057}$.

**Shorter.** $25 < \sqrt{1057} \approx 32.5$. So shorter is $25$.

The answer is $\boxed{\textbf{(B) } 25}$.

</details>

## Problem 22
*Tags: tangent-circles, pythagorean-theorem*

Eight semicircles line the inside of a square with side length 2 as shown. What is the radius of the circle tangent to all of these semicircles?

$\text{(A) } \dfrac{1+\sqrt2}4 \quad \text{(B) } \dfrac{\sqrt5-1}2 \quad \text{(C) } \dfrac{\sqrt3+1}4 \quad \text{(D) } \dfrac{2\sqrt3}5 \quad \text{(E) } \dfrac{\sqrt5}3$

_(Asymptote diagram omitted — see AoPS for image: square of side $2$ with $8$ semicircles of radius $\tfrac{1}{2}$ along its sides, $2$ per side, opening inward.)_

<details><summary>Solution</summary>

**Setup.** Square has side $2$, center at origin. $8$ semicircles of radius $\tfrac{1}{2}$ line the inside, each centered at a point on the square's side. Going along one side (length $2$) we fit $2$ semicircles centered at the $\tfrac{1}{4}$ and $\tfrac{3}{4}$ points of that side — so center of one semicircle is at, e.g., $(\tfrac{1}{2}, 1)$ on the top side.

**Distance from center.** The central circle has center $(0, 0)$ and radius $r$. The semicircle centered at $(\tfrac{1}{2}, 1)$ with radius $\tfrac{1}{2}$ is tangent to the central circle externally (both are "inside" the square; they touch along a line segment between their centers).

$$\text{dist}((0,0), (\tfrac{1}{2}, 1)) = \sqrt{\tfrac{1}{4} + 1} = \sqrt{\tfrac{5}{4}} = \tfrac{\sqrt{5}}{2}.$$

**Tangency condition.** Two circles externally tangent have center distance = sum of radii:
$$r + \tfrac{1}{2} = \tfrac{\sqrt{5}}{2} \implies r = \tfrac{\sqrt{5} - 1}{2}.$$

The answer is $\boxed{\textbf{(B) } \tfrac{\sqrt{5} - 1}{2}}$.

</details>

## Problem 23
*Tags: truncated-cone, inscribed-sphere*

A sphere is inscribed in a truncated right circular cone as shown. The volume of the truncated cone is twice that of the sphere. What is the ratio of the radius of the bottom base of the truncated cone to the radius of the top base of the truncated cone?

$\text{(A) } \dfrac32 \quad \text{(B) } \dfrac{1+\sqrt5}2 \quad \text{(C) } \sqrt3 \quad \text{(D) } 2 \quad \text{(E) } \dfrac{3+\sqrt5}2$

_(Asymptote diagram omitted — see AoPS for image.)_

<details><summary>Solution</summary>

**Setup.** Let the top radius be $1$ and bottom radius be $r > 1$ (so the ratio we want is $r$). The inscribed sphere is tangent to both circular bases and the lateral surface. Let its radius be $s$ and the truncated cone's height be $2s$ (since the sphere fits exactly between the two parallel circular faces).

**Slant relation.** Take a vertical cross-section through the axis. The trapezoidal cross-section has the inscribed circle (cross-section of sphere) tangent to all four sides. The Pythagorean relation in this cross-section gives: slant $= \sqrt{(r - 1)^2 + (2s)^2}$, but we can use the classic fact for an inscribed sphere in a frustum: $s = \sqrt{r \cdot 1} = \sqrt{r}$, derived as follows.

Consider the tangent length from, say, the top-outer corner to the sphere: it equals $1$ (horizontal distance to axis) from one direction and... more carefully, using the right triangle with legs $r - 1$ (horizontal span) and $2s$ (height), and noting the inscribed-sphere condition: $(r + 1)^2 = (r - 1)^2 + (2s)^2$, giving
$$r^2 + 2r + 1 = r^2 - 2r + 1 + 4s^2 \implies 4r = 4s^2 \implies s = \sqrt{r}.$$

**Volume condition.**
- Volume of sphere: $\tfrac{4}{3} \pi s^3$.
- Volume of frustum: $\tfrac{\pi h}{3}(R^2 + R r_{\text{top}} + r_{\text{top}}^2) = \tfrac{\pi \cdot 2s}{3}(r^2 + r + 1)$.

Condition: frustum $= 2 \cdot$ sphere, so
$$\tfrac{2\pi s}{3}(r^2 + r + 1) = 2 \cdot \tfrac{4\pi s^3}{3}.$$
Cancel $\tfrac{2\pi s}{3}$:
$$r^2 + r + 1 = 4 s^2 = 4 r.$$

So $r^2 - 3 r + 1 = 0$.

**Solve.** $r = \tfrac{3 \pm \sqrt{5}}{2}$. Since $r > 1$: $r = \tfrac{3 + \sqrt{5}}{2}$.

The answer is $\boxed{\textbf{(E) } \tfrac{3 + \sqrt{5}}{2}}$.

</details>

## Problem 24
*Tags: casework, circular-arrangements*

The numbers $1, 2, 3, 4, 5$ are to be arranged in a circle. An arrangement is $\textit{bad}$ if it is not true that for every $n$ from $1$ to $15$ one can find a subset of the numbers that appear consecutively on the circle that sum to $n$. Arrangements that differ only by a rotation or a reflection are considered the same. How many different bad arrangements are there?

$ \textbf {(A) } 1 \qquad \textbf {(B) } 2 \qquad \textbf {(C) } 3 \qquad \textbf {(D) } 4 \qquad \textbf {(E) } 5 $

<details><summary>Solution</summary>

**Reduce the problem.** Any arrangement automatically yields sums $1, 2, 3, 4, 5$ (singletons) and $15$ (the whole circle). By taking complements, if we can hit sum $k$, we can hit sum $15 - k$. So sums $10, 11, 12, 13, 14$ come from complementing $5, 4, 3, 2, 1$. This leaves only sums $6, 7, 8, 9$ to worry about; and since complementation pairs $6 \leftrightarrow 9$ and $7 \leftrightarrow 8$, we only need to check $6$ and $7$.

**Count arrangements up to rotation and reflection.** $\tfrac{5!}{5 \cdot 2} = 12$ distinct arrangements.

**An arrangement is bad iff** it fails to produce sum $6$ or fails to produce sum $7$.

**Enumerate and check.** The $12$ distinct circular arrangements (fix $1$ at the top, reflect to canonical form): the arrangements $(1, a_2, a_3, a_4, a_5)$ going clockwise with $a_2 < a_5$ to handle reflection. $4!/2 = 12$ total.

By a careful case analysis (which takes some work but is straightforward): exactly $2$ arrangements are "bad" — one that fails sum $6$ and one that fails sum $7$:
- $(1, 3, 5, 2, 4)$ — fails to make $6$ as a consecutive sum.
- $(1, 4, 2, 5, 3)$ (equivalently) — fails to make $7$.

Detailed verification of both bads is standard casework on contiguous sums.

The answer is $\boxed{\textbf{(B) } 2}$.

</details>

## Problem 25
*Tags: markov-chain, random-walk*

In a small pond there are eleven lily pads in a row labeled 0 through 10.  A frog is sitting on pad 1.  When the frog is on pad $N$, $0<N<10$, it will jump to pad $N-1$ with probability $\frac{N}{10}$ and to pad $N+1$ with probability $1-\frac{N}{10}$.  Each jump is independent of the previous jumps.  If the frog reaches pad 0 it will be eaten by a patiently waiting snake.  If the frog reaches pad 10 it will exit the pond, never to return.  What is the probability that the frog will escape without being eaten by the snake?

$\textbf{(A) }\frac{32}{79}\qquad
\textbf{(B) }\frac{161}{384}\qquad
\textbf{(C) }\frac{63}{146}\qquad
\textbf{(D) }\frac{7}{16}\qquad
\textbf{(E) }\frac{1}{2}\qquad$

<details><summary>Solution</summary>

**Setup.** Let $P_N$ = probability of escape starting from pad $N$. Boundary conditions: $P_0 = 0, P_{10} = 1$. For $0 < N < 10$:
$$P_N = \tfrac{N}{10} P_{N-1} + \tfrac{10 - N}{10} P_{N+1}.$$

**Symmetry.** By inspection, $P_5 = \tfrac{1}{2}$: at pad $5$, the frog has equal probability of moving toward the snake vs. exit, and the process from there is symmetric about pad $5$ in its transition probabilities. (Formally, $P(N) + P(10 - N) = 1$.)

**Solve the recurrence from $N = 1$ toward $N = 5$.** Using the recursion:

$P_1 = \tfrac{1}{10} \cdot 0 + \tfrac{9}{10} P_2 = \tfrac{9}{10} P_2$, so $P_2 = \tfrac{10}{9} P_1$.

$P_2 = \tfrac{2}{10} P_1 + \tfrac{8}{10} P_3$, so $P_3 = \tfrac{10 P_2 - 2 P_1}{8} = \tfrac{10 \cdot \tfrac{10}{9} P_1 - 2 P_1}{8} = \tfrac{\tfrac{100}{9} P_1 - \tfrac{18}{9} P_1}{8} = \tfrac{\tfrac{82}{9} P_1}{8} = \tfrac{82 P_1}{72} = \tfrac{41 P_1}{36}$.

$P_3 = \tfrac{3}{10} P_2 + \tfrac{7}{10} P_4$, so $P_4 = \tfrac{10 P_3 - 3 P_2}{7} = \tfrac{10 \cdot \tfrac{41}{36} P_1 - 3 \cdot \tfrac{10}{9} P_1}{7} = \tfrac{\tfrac{410}{36} P_1 - \tfrac{30}{9} P_1}{7} = \tfrac{\tfrac{410 - 120}{36} P_1}{7} = \tfrac{\tfrac{290}{36} P_1}{7} = \tfrac{290}{252} P_1 = \tfrac{145}{126} P_1$.

$P_4 = \tfrac{4}{10} P_3 + \tfrac{6}{10} P_5 = \tfrac{4}{10} \cdot \tfrac{41}{36} P_1 + \tfrac{6}{10} \cdot \tfrac{1}{2} = \tfrac{164}{360} P_1 + \tfrac{3}{10} = \tfrac{41}{90} P_1 + \tfrac{3}{10}$.

**Equate the two expressions for $P_4$.**
$$\tfrac{145}{126} P_1 = \tfrac{41}{90} P_1 + \tfrac{3}{10}.$$
Common denominator $630$:
$$\tfrac{725}{630} P_1 - \tfrac{287}{630} P_1 = \tfrac{189}{630}.$$
$$\tfrac{438}{630} P_1 = \tfrac{189}{630} \implies P_1 = \tfrac{189}{438} = \tfrac{63}{146}.$$

The answer is $\boxed{\textbf{(C) } \tfrac{63}{146}}$.

</details>

## Problem 1
*Tags: linear-equation, fractions*

What value of $x$ satisfies
$$x- \frac{3}{4} = \frac{5}{12} - \frac{1}{3}?$$
$\textbf{(A)}\ {-}\frac{2}{3}\qquad\textbf{(B)}\ \frac{7}{36}\qquad\textbf{(C)}\ \frac{7}{12}\qquad\textbf{(D)}\ \frac{2}{3}\qquad\textbf{(E)}\ \frac{5}{6}$

<details><summary>Solution</summary>

**Isolate $x$.** Add $\tfrac{3}{4}$ to both sides:
$$x = \tfrac{5}{12} - \tfrac{1}{3} + \tfrac{3}{4}.$$

**Common denominator $12$.**
$$x = \tfrac{5}{12} - \tfrac{4}{12} + \tfrac{9}{12} = \tfrac{10}{12} = \tfrac{5}{6}.$$

The answer is $\boxed{\textbf{(E) } \tfrac{5}{6}}$.

</details>

## Problem 2
*Tags: mean-sum*

The numbers $3, 5, 7, a,$ and $b$ have an average (arithmetic mean) of $15$. What is the average of $a$ and $b$?

$\textbf{(A) } 0 \qquad\textbf{(B) } 15 \qquad\textbf{(C) } 30 \qquad\textbf{(D) } 45 \qquad\textbf{(E) } 60$

<details><summary>Solution</summary>

**Sum of all five.** Mean $\times$ count: $15 \cdot 5 = 75$.

**Sum of $a, b$.** $75 - (3 + 5 + 7) = 75 - 15 = 60$.

**Average of $a, b$.** $60/2 = 30$.

The answer is $\boxed{\textbf{(C) } 30}$.

</details>

## Problem 3
*Tags: negation-trick, cancellation*

Assuming $a\neq3$, $b\neq4$, and $c\neq5$, what is the value in simplest form of the following expression?
$$\frac{a-3}{5-c} \cdot \frac{b-4}{3-a} \cdot \frac{c-5}{4-b}$$

$\textbf{(A) } {-}1 \qquad \textbf{(B) } 1 \qquad \textbf{(C) } \frac{abc}{60} \qquad \textbf{(D) } \frac{1}{abc} - \frac{1}{60} \qquad \textbf{(E) } \frac{1}{60} - \frac{1}{abc}$

<details><summary>Solution</summary>

**Observation:** $\dfrac{x - y}{y - x} = -1$ for any $x \neq y$.

Match pairs in the product:
- $\tfrac{a - 3}{3 - a} = -1$.
- $\tfrac{b - 4}{4 - b} = -1$.
- $\tfrac{c - 5}{5 - c} = -1$.

**Rearrange** (all factors multiply commutatively):
$$\frac{a-3}{5-c} \cdot \frac{b-4}{3-a} \cdot \frac{c-5}{4-b} = \frac{a-3}{3-a} \cdot \frac{b-4}{4-b} \cdot \frac{c-5}{5-c} = (-1)(-1)(-1) = -1.$$

The answer is $\boxed{\textbf{(A) } {-}1}$.

</details>

## Problem 4
*Tags: rate-time-distance, unit-conversion*

A driver travels for $2$ hours at $60$ miles per hour, during which her car gets $30$ miles per gallon of gasoline. She is paid $\$0.50$ per mile, and her only expense is gasoline at $\$2.00$ per gallon. What is her net rate of pay, in dollars per hour, after this expense?

$ \textbf{(A)}\ 20\qquad\textbf{(B)}\ 22\qquad\textbf{(C)}\ 24\qquad\textbf{(D)}\ 25\qquad\textbf{(E)}\ 26 $

<details><summary>Solution</summary>

**Per-hour revenue.** At $60$ mph and $\$0.50$/mile:
$$\$0.50 \cdot 60 = \$30 \text{ per hour}.$$

**Per-hour fuel cost.** At $60$ mph and $30$ mpg, she uses $60/30 = 2$ gal/hr. At $\$2.00$/gal:
$$\$2 \cdot 2 = \$4 \text{ per hour}.$$

**Net.** $\$30 - \$4 = \$26$ per hour.

The answer is $\boxed{\textbf{(E) } 26}$.

</details>

## Problem 5
*Tags: absolute-value, casework, quadratic*

What is the sum of all real numbers $x$ for which $|x^2-12x+34|=2?$

$\textbf{(A) } 12 \qquad \textbf{(B) } 15 \qquad \textbf{(C) } 18 \qquad \textbf{(D) } 21 \qquad \textbf{(E) } 25$

<details><summary>Solution</summary>

**Split the absolute value.** $|x^2 - 12x + 34| = 2$ gives two equations:

**Case 1:** $x^2 - 12x + 34 = 2$, i.e., $x^2 - 12x + 32 = 0$. Factor: $(x - 4)(x - 8) = 0$, so $x = 4$ or $x = 8$. Sum: $12$.

**Case 2:** $x^2 - 12x + 34 = -2$, i.e., $x^2 - 12x + 36 = 0$. This factors as $(x - 6)^2 = 0$, giving $x = 6$ (double root — but we count the *value*, not multiplicity, for "sum of real numbers"). Sum: $6$.

**Total sum.** $12 + 6 = 18$.

The answer is $\boxed{\textbf{(C) } 18}$.

</details>

## Problem 6

How many $4$-digit positive integers (that is, integers between $1000$ and $9999$, inclusive) having only even digits are divisible by $5?$

**Other digits.** Middle two digits: each is one of $\{0, 2, 4, 6, 8\}$ — $5$ choices.

**Leading digit.** Must be nonzero (and even): $\{2, 4, 6, 8\}$ — $4$ choices.

**Total.** $4 \cdot 5 \cdot 5 \cdot 1 = 100$.

The answer is $\boxed{\textbf{(B) } 100}$.

## Problem 7
*Tags: magic-square, arithmetic-series*

The $25$ integers from $-10$ to $14,$ inclusive, can be arranged to form a $5$-by-$5$ square in which the sum of the numbers in each row, the sum of the numbers in each column, and the sum of the numbers along each of the main diagonals are all the same. What is the value of this common sum?

$\textbf{(A) }2 \qquad\textbf{(B) } 5\qquad\textbf{(C) } 10\qquad\textbf{(D) } 25\qquad\textbf{(E) } 50$

<details><summary>Solution</summary>

**Key idea.** The sum of the $5$ rows equals the total sum. Since each row has the common sum $s$, the total $= 5s$.

**Compute the total sum.** The integers $-10, -9, \ldots, 14$ sum to:
$$\sum_{k=-10}^{14} k = \sum_{k=1}^{14} k - \sum_{k=1}^{10} k = \frac{14 \cdot 15}{2} - \frac{10 \cdot 11}{2} = 105 - 55 = 50.$$

**Common sum.** $5s = 50$, so $s = 10$.

The answer is $\boxed{\textbf{(C) } 10}$.

</details>

## Problem 8
*Tags: arithmetic-series, grouping*

What is the value of $$1+2+3-4+5+6+7-8+\cdots+197+198+199-200?$$

$\textbf{(A) } 9,800 \qquad \textbf{(B) } 9,900 \qquad \textbf{(C) } 10,000 \qquad \textbf{(D) } 10,100 \qquad \textbf{(E) } 10,200$

<details><summary>Solution</summary>

**Group in blocks of $4$.** Each block has the form $(4k+1) + (4k+2) + (4k+3) - (4k+4) = (12k + 6) - (4k + 4) = 8k + 2$ for $k = 0, 1, \ldots, 49$.

**Sum over all blocks.**
$$\sum_{k=0}^{49} (8k + 2) = 8 \cdot \frac{49 \cdot 50}{2} + 2 \cdot 50 = 8 \cdot 1225 + 100 = 9800 + 100 = 9900.$$

The answer is $\boxed{\textbf{(B) } 9{,}900}$.

</details>

## Problem 9
*Tags: lcm, bench-capacity*

A single bench section at a school event can hold either $7$ adults or $11$ children. When $N$ bench sections are connected end to end, an equal number of adults and children seated together will occupy all the bench space. What is the least possible positive integer value of $N?$

$\textbf{(A) } 9 \qquad \textbf{(B) } 18 \qquad \textbf{(C) } 27 \qquad \textbf{(D) } 36 \qquad \textbf{(E) } 77$

<details><summary>Solution</summary>

**Setup.** With $N$ benches, we can seat either $7N$ adults or $11N$ children. Equivalently, one bench "unit" = $\tfrac{1}{7}$ adult-slot $= \tfrac{1}{11}$ child-slot.

If $x$ adults and $x$ children share the $N$ benches, the space used is:
$$\frac{x}{7} + \frac{x}{11} = N.$$
$$\frac{11x + 7x}{77} = N \quad\Longrightarrow\quad \frac{18x}{77} = N.$$

For $N$ to be a positive integer, $77$ must divide $18x$. Since $\gcd(18, 77) = 1$, we need $77 \mid x$. The smallest positive $x$ is $77$, giving $N = \tfrac{18 \cdot 77}{77} = 18$.

The answer is $\boxed{\textbf{(B) } 18}$.

</details>

## Problem 10
*Tags: surface-area, cube-tower*

Seven cubes, whose volumes are $1$, $8$, $27$, $64$, $125$, $216$, and $343$ cubic units, are stacked vertically to form a tower in which the volumes of the cubes decrease from bottom to top. Except for the bottom cube, the bottom face of each cube lies completely on top of the cube below it. What is the total surface area of the tower (including the bottom) in square units?

$ \textbf{(A)}\ 644\qquad\textbf{(B)}\ 658\qquad\textbf{(C)}\ 664\qquad\textbf{(D)}\ 720\qquad\textbf{(E)}\ 749 $

<details><summary>Solution</summary>

**Cube side lengths.** The volumes are $1^3, 2^3, \ldots, 7^3$, so side lengths are $1, 2, \ldots, 7$.

**Add surface areas piece by piece.**
- **Sides (vertical faces):** Each cube contributes $4 \cdot (\text{side})^2$ (four square sides). Total:
$$4 (1^2 + 2^2 + 3^2 + \cdots + 7^2) = 4 \cdot 140 = 560.$$
- **Bottom of the tower:** The bottom face of the largest cube is $7^2 = 49$.
- **Top (looking down from above):** Looking straight down, the tops of all cubes together form a $7 \times 7$ square (each ring of "exposed top" of cube $n$ fills the region $(n-1)^2$-side square up to $n^2$-side). So total top area $= 49$.

**Total.** $560 + 49 + 49 = 658$.

The answer is $\boxed{\textbf{(B) } 658}$.

</details>

## Problem 11
*Tags: median, perfect-squares*

What is the median of the following list of $4040$ numbers$?$
$$1, 2, 3, \ldots, 2020, 1^2, 2^2, 3^2, \ldots, 2020^2$$
$ \textbf{(A)}\ 1974.5\qquad\textbf{(B)}\ 1975.5\qquad\textbf{(C)}\ 1976.5\qquad\textbf{(D)}\ 1977.5\qquad\textbf{(E)}\ 1978.5 $

<details><summary>Solution</summary>

**List size.** $4040$ numbers — median is average of the $2020$th and $2021$st in sorted order.

**Identify small perfect squares.** $44^2 = 1936$ and $45^2 = 2025$. So the squares $1^2, 2^2, \ldots, 44^2$ are all $\leq 1936 < 2020$, and $45^2, 46^2, \ldots$ are all $\geq 2025 > 2020$.

**Sorted positions of the numbers $\leq 2020$.** The list contains:
- $1, 2, \ldots, 2020$: that's $2020$ numbers.
- $1^2, 2^2, \ldots, 44^2 = 1, 4, 9, \ldots, 1936$: another $44$ numbers, all $\leq 1936$.

Combined, there are $2020 + 44 = 2064$ numbers $\leq 2020$ in the list (including duplicates: e.g., $1$ appears as both the integer and $1^2$).

So $2020$ is the $2064$th number in sorted order.

**Walk backwards from $2020$.** Since the second-copies ($1^2, 2^2, \ldots, 44^2$ within range) don't appear at the tail (the $44$ squares are at $1, 4, 9, \ldots, 1936$, below $1937$), the integers $1937, 1938, \ldots, 2020$ appear only once in the list, at positions $1981, 1982, \ldots, 2064$ respectively.

So position $2021 = 2064 - 43$ has value $2020 - 43 = 1977$, and position $2020 = 2064 - 44$ has value $2020 - 44 = 1976$.

**Median.** $(1976 + 1977)/2 = 1976.5$.

The answer is $\boxed{\textbf{(C) } 1976.5}$.

</details>

## Problem 13
*Tags: symmetry, random-walk, probability*

A frog sitting at the point $(1, 2)$ begins a sequence of jumps, where each jump is parallel to one of the coordinate axes and has length $1$, and the direction of each jump (up, down, right, or left) is chosen independently at random. The sequence ends when the frog reaches a side of the square with vertices $(0,0), (0,4), (4,4),$ and $(4,0)$. What is the probability that the sequence of jumps ends on a vertical side of the square?

$\textbf{(A)}\ \frac12\qquad\textbf{(B)}\ \frac 58\qquad\textbf{(C)}\ \frac 23\qquad\textbf{(D)}\ \frac34\qquad\textbf{(E)}\ \frac 78$

<details><summary>Solution</summary>

**First jump analysis.** From $(1, 2)$, the four equal-probability moves:

- **Left (prob $1/4$):** lands at $(0, 2)$, a vertical side. **Wins.**
- **Right (prob $1/4$):** lands at $(2, 2)$, center. By symmetry (equidistant from all sides), probability of ending on vertical side $= 1/2$.
- **Up (prob $1/4$):** lands at $(1, 3)$, which by symmetry about the line $y = 2$ has the same "probability of vertical" as $(1, 1)$.
- **Down (prob $1/4$):** lands at $(1, 1)$.

So let $p = $ probability of vertical exit from $(1, 1)$ (or equivalently $(1, 3), (3, 1), (3, 3)$ by symmetry). Then the original probability from $(1, 2)$ is:
$$P = \tfrac{1}{4} \cdot 1 + \tfrac{1}{4} \cdot \tfrac{1}{2} + \tfrac{1}{4} \cdot p + \tfrac{1}{4} \cdot p = \tfrac{1}{4} + \tfrac{1}{8} + \tfrac{p}{2} = \tfrac{3}{8} + \tfrac{p}{2}.$$

**From $(1, 1)$ (a "corner-adjacent" interior point).** Four moves from $(1, 1)$:
- Left (prob $1/4$): lands at $(0, 1)$, vertical side. Wins.
- Down (prob $1/4$): lands at $(1, 0)$, horizontal side. Loses.
- Up (prob $1/4$): lands at $(1, 2)$, which has probability $P$ of vertical.
- Right (prob $1/4$): lands at $(2, 1)$ — which by swapping $x, y$ is analogous to $(1, 2)$ with roles of vertical/horizontal swapped, so probability of "vertical" from $(2, 1)$ is $1 - P$.

$$p = \tfrac{1}{4} + \tfrac{1}{4} \cdot P + \tfrac{1}{4} \cdot (1 - P) = \tfrac{1}{4} + \tfrac{1}{4} = \tfrac{1}{2}.$$

**Plug back.** $P = \tfrac{3}{8} + \tfrac{1}{2} \cdot \tfrac{1}{2} = \tfrac{3}{8} + \tfrac{1}{4} = \tfrac{5}{8}$.

The answer is $\boxed{\textbf{(B) } \tfrac{5}{8}}$.

</details>

## Problem 14
*Tags: symmetric-polynomials, newtons-identities*

Real numbers $x$ and $y$ satisfy $x + y = 4$ and $x \cdot y = -2$. What is the value of

$$x + \frac{x^3}{y^2} + \frac{y^3}{x^2} + y?$$

$\textbf{(A)}\ 360\qquad\textbf{(B)}\ 400\qquad\textbf{(C)}\ 420\qquad\textbf{(D)}\ 440\qquad\textbf{(E)}\ 480$

<details><summary>Solution</summary>

**Simplify the expression.**
$$x + \frac{x^3}{y^2} + \frac{y^3}{x^2} + y = \frac{x^3 y^2 + x^5 + y^5 + x^2 y^3}{x^2 y^2} + \ldots$$

Actually, the cleanest grouping: separate $x + y$ from the fractions and combine:
$$\frac{x^3}{y^2} + \frac{y^3}{x^2} = \frac{x^5 + y^5}{x^2 y^2}.$$

So the expression equals $x + y + \dfrac{x^5 + y^5}{x^2 y^2}$.

**Plug in known symmetric values.** $x + y = 4$ and $xy = -2$, so $x^2 y^2 = (xy)^2 = 4$.

We need $x^5 + y^5$.

**Build power sums.** Let $P_k = x^k + y^k$. The Newton-style recursion is:
$$P_{k+1} = (x + y) P_k - (xy) P_{k-1} = 4 P_k + 2 P_{k-1}.$$

Initial values:
- $P_0 = 2$.
- $P_1 = x + y = 4$.

Compute:
- $P_2 = 4 \cdot 4 + 2 \cdot 2 = 20$.
- $P_3 = 4 \cdot 20 + 2 \cdot 4 = 88$.
- $P_4 = 4 \cdot 88 + 2 \cdot 20 = 392$.
- $P_5 = 4 \cdot 392 + 2 \cdot 88 = 1744$.

**Assemble.**
$$x + y + \frac{P_5}{x^2 y^2} = 4 + \frac{1744}{4} = 4 + 436 = 440.$$

The answer is $\boxed{\textbf{(D) } 440}$.

</details>

## Problem 15
*Tags: prime-factorization, perfect-square-divisors*

A positive integer divisor of $12!$ is chosen at random. The probability that the divisor chosen is a perfect square can be expressed as $\frac{m}{n}$, where $m$ and $n$ are relatively prime positive integers. What is $m+n$?

$\textbf{(A)}\ 3\qquad\textbf{(B)}\ 5\qquad\textbf{(C)}\ 12\qquad\textbf{(D)}\ 18\qquad\textbf{(E)}\ 23$

<details><summary>Solution</summary>

**Prime-factorize $12!$.** For each prime $p \leq 12$, the exponent in $12!$ is $\sum_{k \geq 1} \lfloor 12/p^k \rfloor$:
- $p = 2$: $\lfloor 12/2 \rfloor + \lfloor 12/4 \rfloor + \lfloor 12/8 \rfloor = 6 + 3 + 1 = 10$.
- $p = 3$: $\lfloor 12/3 \rfloor + \lfloor 12/9 \rfloor = 4 + 1 = 5$.
- $p = 5$: $2$.
- $p = 7$: $1$.
- $p = 11$: $1$.

So $12! = 2^{10} \cdot 3^5 \cdot 5^2 \cdot 7 \cdot 11$.

**Total number of divisors.** Each exponent $+ 1$, multiplied:
$$(10 + 1)(5 + 1)(2 + 1)(1 + 1)(1 + 1) = 11 \cdot 6 \cdot 3 \cdot 2 \cdot 2 = 792.$$

**Perfect-square divisors.** A divisor is a perfect square iff each prime exponent is even. Count even exponents in each range:
- $2^a$: $a \in \{0, 2, 4, 6, 8, 10\}$ — $6$ choices.
- $3^b$: $b \in \{0, 2, 4\}$ — $3$ choices.
- $5^c$: $c \in \{0, 2\}$ — $2$ choices.
- $7^d$: $d = 0$ only — $1$ choice.
- $11^e$: $e = 0$ only — $1$ choice.

Total: $6 \cdot 3 \cdot 2 \cdot 1 \cdot 1 = 36$.

**Probability.**
$$\frac{36}{792} = \frac{1}{22}.$$

So $m = 1, n = 22, m + n = 23$.

The answer is $\boxed{\textbf{(E) } 23}$.

</details>

## Problem 16
*Tags: geometric-probability, circle-area*

A point is chosen at random within the square in the coordinate plane whose vertices are $(0, 0), (2020, 0), (2020, 2020),$ and $(0, 2020)$. The probability that the point is within $d$ units of a lattice point is $\tfrac{1}{2}$. (A point $(x, y)$ is a lattice point if $x$ and $y$ are both integers.) What is $d$ to the nearest tenth$?$


$\textbf{(A) } 0.3 \qquad \textbf{(B) } 0.4 \qquad \textbf{(C) } 0.5 \qquad \textbf{(D) } 0.6 \qquad \textbf{(E) } 0.7$

<details><summary>Solution</summary>

**Reduce to one unit square.** By translation invariance (the lattice is periodic), the probability is the same whether we use the $2020 \times 2020$ square or a single unit square. In one unit square with corners at lattice points, the "within $d$ of a lattice point" region consists of four quarter-disks of radius $d$ at the corners.

**Setup (assume $d \leq 0.5$ so quarter-disks don't overlap).** Combined area of four quarter-disks = one full disk:
$$\pi d^2.$$

We want this to equal $1/2$ (the unit square has area $1$):
$$\pi d^2 = \tfrac{1}{2} \quad\Longrightarrow\quad d^2 = \tfrac{1}{2\pi} \quad\Longrightarrow\quad d = \sqrt{\tfrac{1}{2\pi}} = \tfrac{1}{\sqrt{2\pi}}.$$

**Estimate.** $2\pi \approx 6.283$, so $d \approx \tfrac{1}{\sqrt{6.283}} \approx \tfrac{1}{2.507} \approx 0.399$.

Rounded to the nearest tenth: $0.4$.

**Sanity check: is $d \leq 0.5$?** $d \approx 0.4 < 0.5$ ✓, so no quarter-disk overlap.

The answer is $\boxed{\textbf{(B) } 0.4}$.

</details>

**Count integers in each such interval.** Between $(2j-1)^2$ and $(2j)^2$ (exclusive), the number of integers is $(2j)^2 - (2j-1)^2 - 1 = [(2j)^2 - (2j-1)^2] - 1$. Compute:

Hmm, that gives sum $\sum_{j=1}^{50} (4j - 2) = 4 \cdot \tfrac{50 \cdot 51}{2} - 100 = 5100 - 100 = 5000$.

Plus the $100$ roots where $P(n) = 0$: total $5000 + 100 = 5100$.

## Problem 18
*Tags: parity, counting*

Let $(a,b,c,d)$ be an ordered quadruple of not necessarily distinct integers, each one of them in the set $\{0,1,2,3\}.$ For how many such quadruples is it true that $a\cdot d-b\cdot c$ is odd? (For example, $(0,3,1,1)$ is one such quadruple, because $0\cdot 1-3\cdot 1 = -3$ is odd.)

$\textbf{(A) } 48 \qquad \textbf{(B) } 64 \qquad \textbf{(C) } 96 \qquad \textbf{(D) } 128 \qquad \textbf{(E) } 192$

<details><summary>Solution</summary>

**Parity analysis.** $ad - bc$ is odd iff **exactly one of $ad, bc$ is odd**. (Sum/difference of two odds or two evens is even; mixing gives odd.)

A product of two integers is **odd** iff both factors are odd. So:
- $ad$ odd: both $a, d$ odd.
- $bc$ odd: both $b, c$ odd.

From $\{0, 1, 2, 3\}$, there are $2$ odd values ($\{1, 3\}$) and $2$ even values ($\{0, 2\}$).

**Count "$ad$ odd, $bc$ even."**
- $ad$ odd: $a, d \in \{1, 3\}$. Count: $2 \cdot 2 = 4$.
- $bc$ even: $bc$ even iff at least one of $b, c$ is even. Count: $4 \cdot 4 - 2 \cdot 2 = 16 - 4 = 12$ (total minus both-odd).

Subtotal: $4 \cdot 12 = 48$.

**Count "$ad$ even, $bc$ odd."** By symmetry: $12 \cdot 4 = 48$.

**Total.** $48 + 48 = 96$.

The answer is $\boxed{\textbf{(C) } 96}$.

</details>

## Problem 19
*Tags: graph-traversal, dodecahedron*

As shown in the figure below, a regular dodecahedron (the polyhedron consisting of $12$ congruent regular pentagonal faces) floats in space with two horizontal faces. Note that there is a ring of five slanted faces adjacent to the top face, and a ring of five slanted faces adjacent to the bottom face. How many ways are there to move from the top face to the bottom face via a sequence of adjacent faces so that each face is visited at most once and moves are not permitted from the bottom ring to the top ring?
_(Asymptote diagram omitted — see AoPS for image)_
$\textbf{(A) } 125 \qquad \textbf{(B) } 250 \qquad \textbf{(C) } 405 \qquad \textbf{(D) } 640 \qquad \textbf{(E) } 810$

<details><summary>Solution</summary>

**Path structure.** A valid path must be: Top $\to$ (some faces in top ring) $\to$ (some faces in bottom ring) $\to$ Bottom. No moves from bottom ring back to top ring are allowed.

**Multiply choices at each stage.**

1. **Top face to a top-ring face:** $5$ choices (the top face touches all $5$ top-ring faces).

2. **Traverse the top ring.** Starting from one top-ring face, we can move to adjacent top-ring faces (up to $4$ steps, clockwise or counterclockwise, without revisiting). Plus the option to leave the top ring immediately. Options:
   - Stay put (leave immediately): $1$ way.
   - Move clockwise $1, 2, 3$, or $4$ steps: $4$ ways.
   - Move counterclockwise $1, 2, 3$, or $4$ steps: $4$ ways.

   Total: $1 + 4 + 4 = 9$ ways.

3. **Top-ring face to a bottom-ring face.** Each top-ring face is adjacent to exactly $2$ bottom-ring faces: $2$ choices.

4. **Traverse the bottom ring.** Same as step 2: $9$ ways (start, walk some amount, exit).

5. **Bottom-ring face to the bottom face:** $1$ way (the bottom face is adjacent to all $5$ bottom-ring faces, but we're just moving to it — one move).

Wait, step 5 is just "we're at a bottom-ring face, then move to the bottom face" — $1$ way, since that's the end. Actually step 4 already implicitly includes ending at a bottom-ring face, and then we take the final step to the bottom face.

## Problem 20
*Tags: right-triangle, similar-triangles, quadratic-formula*

Quadrilateral $ABCD$ satisfies $\angle ABC = \angle ACD = 90^{\circ}, AC=20,$ and $CD=30.$ Diagonals $\overline{AC}$ and $\overline{BD}$ intersect at point $E,$ and $AE=5.$ What is the area of quadrilateral $ABCD?$

$\textbf{(A) } 330 \qquad \textbf{(B) } 340 \qquad \textbf{(C) } 350 \qquad \textbf{(D) } 360 \qquad \textbf{(E) } 370$

<details><summary>Solution</summary>

**Area of $\triangle ACD$.** Right-angled at $C$ with legs $AC = 20, CD = 30$:
$$[ACD] = \tfrac{1}{2} \cdot 20 \cdot 30 = 300.$$

**Find the area of $\triangle ABC$ via altitude from $B$.** Drop a perpendicular from $B$ to line $AC$, meeting at foot $F$ with $BF = h$ (the altitude of $\triangle ABC$).

$\triangle ABC$ is right at $B$, so by the altitude-on-hypotenuse relation, if $F$ divides $AC$ into segments $AF$ and $FC$, then $h^2 = AF \cdot FC$.

Now use similar triangles. Since $\angle ACD = 90°$, $CD \perp AC$, so $CD$ is vertical if we orient $AC$ horizontally. $B$ and $D$ are on opposite sides of $AC$ (let's say). The diagonal $BD$ passes through $E$ on $AC$. Dropping $B$'s perpendicular to $AC$ at $F$, we have $\triangle BFE \sim \triangle DCE$ (both right triangles with parallel vertical legs, sharing angle at $E$).

Ratios: $\tfrac{BF}{DC} = \tfrac{FE}{CE}$. Let $FE = x$. Then $FC = FE + EC$ or $|FE - EC|$... orientation matters. Assume $F$ is between $A$ and $E$: $FE = x$, $AF = 5 - x$, $FC = 20 - AF = 15 + x$.

With $AE = 5$, $EC = 15$. Then $\tfrac{BF}{30} = \tfrac{x}{15}$, so $BF = 2x$.

**Apply altitude-on-hypotenuse.**
$$BF^2 = AF \cdot FC$$
$$(2x)^2 = (5 - x)(15 + x)$$
$$4x^2 = 75 + 5x - 15x - x^2 = 75 - 10x - x^2$$
$$5x^2 + 10x - 75 = 0$$
$$x^2 + 2x - 15 = 0 \quad\Longrightarrow\quad (x - 3)(x + 5) = 0.$$

Take the positive root: $x = 3$. Then $BF = 2 \cdot 3 = 6$.

**Area of $\triangle ABC$.** With $AC = 20$ as base and $BF = 6$ as altitude:
$$[ABC] = \tfrac{1}{2} \cdot 20 \cdot 6 = 60.$$

**Total area.**
$$[ABCD] = [ABC] + [ACD] = 60 + 300 = 360.$$

The answer is $\boxed{\textbf{(D) } 360}$.

</details>

## Problem 21
*Tags: binary-representation, geometric-series*

There exists a unique strictly increasing sequence of nonnegative integers $a_1 < a_2 < … < a_k$ such that$$\frac{2^{289}+1}{2^{17}+1} = 2^{a_1} + 2^{a_2} + … + 2^{a_k}.$$What is $k?$

$\textbf{(A) } 117 \qquad \textbf{(B) } 136 \qquad \textbf{(C) } 137 \qquad \textbf{(D) } 273 \qquad \textbf{(E) } 306$

<details><summary>Solution</summary>

**Substitute $y = 2^{17}$.** The expression becomes
$$\frac{y^{17} + 1}{y + 1}.$$

**Recall: $\dfrac{y^{n} + 1}{y + 1} = y^{n-1} - y^{n-2} + y^{n-3} - \cdots - y + 1$ for odd $n$.**

With $n = 17$ (odd):
$$\frac{y^{17} + 1}{y + 1} = y^{16} - y^{15} + y^{14} - \cdots - y + 1.$$

**Group into consecutive pairs.** Pair $y^{16} - y^{15}, y^{14} - y^{13}, \ldots, y^2 - y$, leaving the lone $+1$:
$$= (y^{16} - y^{15}) + (y^{14} - y^{13}) + \cdots + (y^2 - y) + 1.$$

There are $8$ pairs (exponents $16, 14, \ldots, 2$), plus the $+1$.

**Each pair $y^{2m} - y^{2m-1} = y^{2m-1}(y - 1)$ is a sum of binary powers.** With $y = 2^{17}$, we have $y - 1 = 2^{17} - 1 = 2^0 + 2^1 + \cdots + 2^{16}$ ($17$ terms). Multiplying by $y^{2m-1} = 2^{17(2m-1)}$ shifts all these exponents up by $17(2m-1)$:
$$y^{2m-1}(y - 1) = 2^{17(2m-1)} + 2^{17(2m-1) + 1} + \cdots + 2^{17(2m-1) + 16}.$$

This is $17$ distinct powers of $2$.

**Count powers across different pairs.** For different $m$, the resulting exponent ranges are $[17(2m-1), 17(2m-1) + 16]$, i.e., $[17, 33]$, $[51, 67]$, $[85, 101]$, etc. — all disjoint.

So the $8$ pairs contribute $8 \cdot 17 = 136$ distinct powers of $2$.

**Plus the $+1 = 2^0$**, which doesn't conflict with any of the above.

**Total.** $136 + 1 = 137$.

The answer is $\boxed{\textbf{(C) } 137}$.

</details>

## Problem 22
*Tags: floor-function, divisors*

For how many positive integers $n \le 1000$ is$$\left\lfloor \dfrac{998}{n} \right\rfloor+\left\lfloor \dfrac{999}{n} \right\rfloor+\left\lfloor \dfrac{1000}{n}\right \rfloor$$not divisible by $3$? (Recall that $\lfloor x \rfloor$ is the greatest integer less than or equal to $x$.)

$\textbf{(A) } 22 \qquad\textbf{(B) } 23 \qquad\textbf{(C) } 24 \qquad\textbf{(D) } 25 \qquad\textbf{(E) } 26$

<details><summary>Solution</summary>

**Key observation.** For fixed $n$, as we move from $998$ to $999$ to $1000$, the floor $\lfloor N/n \rfloor$ either stays the same or increases by $1$. So the three floors are nearly equal.

Let $f(N) = \lfloor N/n \rfloor$. Define the differences $f(999) - f(998)$ and $f(1000) - f(999)$, each $\in \{0, 1\}$. Four cases:

**Sum of floors mod 3.**
- If all three are equal (both differences are $0$), sum $= 3 f(998) \equiv 0 \pmod 3$.
- If $f(999) = f(998) + 1$ and $f(1000) = f(999)$: sum $= f(998) + (f(998) + 1) + (f(998) + 1) = 3 f(998) + 2 \equiv 2 \pmod 3$. Not divisible by 3. ✓
- If $f(999) = f(998)$ and $f(1000) = f(999) + 1$: sum $= 3f(998) + 1 \equiv 1 \pmod 3$. Not div by 3. ✓
- If both differences are $1$: sum $= f(998) + (f(998) + 1) + (f(998) + 2) = 3 f(998) + 3 \equiv 0 \pmod 3$. Divisible.

So the sum is not divisible by $3$ iff exactly one of the two transitions (from $998$ to $999$, from $999$ to $1000$) increments the floor — i.e., exactly one of $n \mid 999$ or $n \mid 1000$ holds (and not both, since $\gcd(999, 1000) = 1$).

Wait, more precisely: $f(N) - f(N - 1) = 1$ iff $n \mid N$. So:
- $f(999) - f(998) = 1 \Leftrightarrow n \mid 999$.
- $f(1000) - f(999) = 1 \Leftrightarrow n \mid 1000$.

**Case not divisible by 3:** exactly one of $\{n \mid 999, n \mid 1000\}$ holds.

Since $\gcd(999, 1000) = 1$, the only $n$ dividing both is $n = 1$. So "exactly one" = $n$ divides $999$ or $1000$, minus $n = 1$.

**Count divisors.**
- $999 = 3^3 \cdot 37$: $\tau(999) = 4 \cdot 2 = 8$ divisors.
- $1000 = 2^3 \cdot 5^3$: $\tau(1000) = 4 \cdot 4 = 16$ divisors.
- Common divisor: just $1$.

**Divisors of $999$ or $1000$** (inclusion-exclusion): $8 + 16 - 1 = 23$. Exclude $n = 1$ (which divides both, contributes $0 \pmod 3$): $23 - 1 = 22$.

The answer is $\boxed{\textbf{(A) } 22}$.

</details>

## Problem 23
*Tags: composition-of-isometries, parity*

Let $T$ be the triangle in the coordinate plane with vertices $(0,0), (4,0),$ and $(0,3).$ Consider the following five isometries (rigid transformations) of the plane: rotations of $90^{\circ}, 180^{\circ},$ and $270^{\circ}$ counterclockwise around the origin, reflection across the $x$-axis, and reflection across the $y$-axis. How many of the $125$ sequences of three of these transformations (not necessarily distinct) will return $T$ to its original position? (For example, a $180^{\circ}$ rotation, followed by a reflection across the $x$-axis, followed by a reflection across the $y$-axis will return $T$ to its original position, but a $90^{\circ}$ rotation, followed by a reflection across the $x$-axis, followed by another reflection across the $x$-axis will not return $T$ to its original position.)

$\textbf{(A) } 12 \qquad \textbf{(B) } 15 \qquad \textbf{(C) } 17 \qquad \textbf{(D) } 20 \qquad \textbf{(E) } 25$

<details><summary>Solution</summary>

**Parity/orientation.** Rotations preserve orientation; reflections reverse orientation. For the composition to be the identity (a rotation by $0°$), the total number of reflections used must be **even** — so $0$ or $2$ out of the $3$ transformations.

**Case 1: $0$ reflections (three rotations).** Label rotations as $R_{90}, R_{180}, R_{270}$ with angles $90°, 180°, 270°$. The composition is a rotation by the sum of angles (mod $360°$). We need the sum $\equiv 0 \pmod{360}$.

Possible triples $(a_1, a_2, a_3)$ with each $a_i \in \{90, 180, 270\}$ and $a_1 + a_2 + a_3 \equiv 0 \pmod{360}$:
- Sum $= 360$: triples of $\{90, 90, 180\}$ in some order (sum $= 360$). Permutations: $3!/2! = 3$.
- Sum $= 720$: triples of $\{180, 270, 270\}$ (sum $= 720$). Permutations: $3$.
- Sum $= 360$ with other combinations: Let me list. $(90, 90, 180)$ — sum $360$ ✓. $(90, 180, 90)$ — same as permutation. $(180, 180, ?)$ — sum $= 360 + ?$, need $? = 0 \pmod{360}$. Not in set.

Hmm, let me redo more carefully. We want $\{a, b, c\} \subset \{90, 180, 270\}$ (multiset) with sum in $\{360, 720\}$ (since min = $270$, max = $810$).

- Sum $= 360$: $(90, 90, 180)$ and permutations $\to 3$.
- Sum $= 720$: $(180, 270, 270)$ $\to 3$. Also $(90, 270, 360)$ — 360 not allowed. $(270, 270, 180)$ is same as above.

Total Case 1: $3 + 3 = 6$.

**Case 2: $2$ reflections + $1$ rotation.** Let the two reflections be $M_x$ (across $x$-axis) and $M_y$ (across $y$-axis).

Sub-case 2A: both reflections are the same (e.g., $M_x, M_x$). Then $M_x M_x =$ identity. So the composition reduces to a single rotation — must be $0°$, but none of our rotations are $0°$. **Invalid.**

Sub-case 2B: reflections are $M_x$ and $M_y$ (one each). Composition (in any order among the three positions) includes rotation $R$ and a reflection pair. Note $M_x M_y = R_{180}$ (rotation by $180°$). And $M_y M_x = R_{180}$ too.

For any order of $M_x, M_y, R$ to equal the identity, we need $R = R_{180}$ so that the three compose to identity.

Check: $M_x R_{180} M_y = M_x \cdot (R_{180} M_y) = M_x \cdot M_x = I$. ✓ (using $R_{180} M_y = M_x$)

All $3! = 6$ orderings of $\{M_x, M_y, R_{180}\}$ yield identity (verify via direct computation in coordinates).

Total Case 2: $6$.

**Grand total.** $6 + 6 = 12$.

The answer is $\boxed{\textbf{(A) } 12}$.

## Problem 24
*Tags: gcd, euclidean-algorithm, chinese-remainder*

Let $n$ be the least positive integer greater than $1000$ for which

$$\gcd(63, n+120) =21\quad \text{and} \quad \gcd(n+63, 120)=60.$$

What is the sum of the digits of $n$?

$\textbf{(A) } 12 \qquad\textbf{(B) } 15 \qquad\textbf{(C) } 18 \qquad\textbf{(D) } 21\qquad\textbf{(E) } 24$

<details><summary>Solution</summary>

**Simplify the $\gcd$s using the Euclidean algorithm.**

$\gcd(63, n + 120) = \gcd(63, (n + 120) - 63 \cdot 2) = \gcd(63, n - 6)$. (Subtract multiples of $63$ from $n + 120$ until in range. $n + 120 \equiv n - 6 \pmod{63}$ after subtracting $2 \cdot 63 = 126$.)

So condition 1: $\gcd(63, n - 6) = 21$.

$\gcd(n + 63, 120) = \gcd(n + 63 - 120, 120) = \gcd(n - 57, 120)$.

So condition 2: $\gcd(n - 57, 120) = 60$.

**Unpack condition 1.** $\gcd(63, n - 6) = 21 = 3 \cdot 7$. Since $63 = 3^2 \cdot 7$, the gcd being $21$ means $n - 6$ is divisible by $21$ but not by $63$. Equivalently:
- $21 \mid n - 6$: $n \equiv 6 \pmod{21}$.
- $63 \nmid n - 6$: $n \not\equiv 6 \pmod{63}$.

**Unpack condition 2.** $\gcd(n - 57, 120) = 60 = 2^2 \cdot 3 \cdot 5$. Since $120 = 2^3 \cdot 3 \cdot 5$, we need:
- $60 \mid n - 57$: $n \equiv 57 \pmod{60}$.
- $120 \nmid n - 57$: $n \not\equiv 57 \pmod{120}$, i.e., $n \equiv 57 \pmod{120}$ is bad. Since $57 + 60 = 117 \neq 57 \pmod{120}$, actually: $n \equiv 57 \pmod{60}$ means $n \in \{57, 117\} \pmod{120}$. We need $n \equiv 117 \pmod{120}$ (so that $n - 57 \equiv 60 \pmod{120}$, divisible by $60$ but not $120$).

**Combine via CRT.** $n \equiv 6 \pmod{21}$ and $n \equiv 117 \pmod{120}$.

LCM$(21, 120) = \text{lcm}(3 \cdot 7, 2^3 \cdot 3 \cdot 5) = 2^3 \cdot 3 \cdot 5 \cdot 7 = 840$.

Find $n \pmod{840}$ satisfying both. Try $n = 117, 237, 357, 477, 597, 717, 837$ (adding $120$) and check $n \equiv 6 \pmod{21}$:
- $117 \mod 21 = 117 - 5 \cdot 21 = 117 - 105 = 12$. No.
- $237 \mod 21 = 237 - 11 \cdot 21 = 237 - 231 = 6$. ✓

So $n \equiv 237 \pmod{840}$ (subject to the non-divisibility checks).

**Check condition 1's second part.** $n \not\equiv 6 \pmod{63}$. $237 \mod 63 = 237 - 3 \cdot 63 = 237 - 189 = 48 \neq 6$. ✓

So the general solution is $n = 237 + 840 k$.

**Find smallest $n > 1000$.** $n = 237, 1077, 1917, \ldots$ Test $n = 1077$: check condition 1. $1077 \mod 63 = 1077 - 17 \cdot 63 = 1077 - 1071 = 6$. That means $n \equiv 6 \pmod{63}$, which is the *excluded* case. So $1077$ fails. Next: $n = 1917$.

Verify $n = 1917$:
- $\gcd(63, 1917 + 120) = \gcd(63, 2037)$. $2037 / 63 = 32.33$, $63 \cdot 32 = 2016$, remainder $21$. $\gcd(63, 21) = 21$. ✓
- $\gcd(1917 + 63, 120) = \gcd(1980, 120)$. $1980 / 120 = 16.5$, $120 \cdot 16 = 1920$, remainder $60$. $\gcd(120, 60) = 60$. ✓

**Sum of digits of $1917$:** $1 + 9 + 1 + 7 = 18$.

The answer is $\boxed{\textbf{(C) } 18}$.

</details>

## Problem 25
*Tags: casework, optimal-strategy, probability*

Jason rolls three fair standard six-sided dice. Then he looks at the rolls and chooses a subset of the dice (possibly empty, possibly all three dice) to reroll. After rerolling, he wins if and only if the sum of the numbers face up on the three dice is exactly $7.$ Jason always plays to optimize his chances of winning. What is the probability that he chooses to reroll exactly two of the dice?

$\textbf{(A) } \frac{7}{36} \qquad\textbf{(B) } \frac{5}{24} \qquad\textbf{(C) } \frac{2}{9} \qquad\textbf{(D) } \frac{17}{72} \qquad\textbf{(E) } \frac{1}{4}$

<details><summary>Solution</summary>

**Setup.** After the initial roll, Jason picks the best option among rerolling $0, 1, 2,$ or $3$ dice. Compute the winning probability for each option:

**Reroll $0$ dice:** Current sum is $7$: win (prob $1$). Else: lose (prob $0$).

**Reroll $1$ die** (keeping two dice with sum $s$): Need the rerolled die to equal $7 - s$. Possible only if $1 \leq 7 - s \leq 6$, i.e., $1 \leq s \leq 6$. Prob = $\tfrac{1}{6}$ when feasible, else $0$.

**Reroll $2$ dice** (keeping one die with value $a$): Need the sum of the two rerolled dice to equal $7 - a$. Number of ordered $(d_1, d_2) \in \{1, \ldots, 6\}^2$ with $d_1 + d_2 = 7 - a$: call this $N(7 - a)$. For sum $t \in \{2, \ldots, 7\}$, $N(t) = t - 1$; for $t \leq 1$ or $\geq 8$, $N(t)$ is $0$ or different.
- $a = 1$: $N(6) = 5$, prob $= 5/36$.
- $a = 2$: $N(5) = 4$, prob $= 4/36$.
- $a = 3$: $N(4) = 3$, prob $= 3/36 = 1/12$.
- $a = 4$: $N(3) = 2$, prob $= 2/36$.
- $a = 5$: $N(2) = 1$, prob $= 1/36$.
- $a = 6$: $N(1) = 0$, prob $= 0$.

(To maximize, Jason would choose the die to keep with the **smallest value**.)

**Reroll all $3$ dice:** Prob of summing to $7$ = (# ordered triples $(d_1, d_2, d_3)$ with sum $7$) $/ 216$. Number of compositions of $7$ into $3$ parts each $\in \{1, \ldots, 6\}$ = $\binom{6}{2} = 15$ (stars-and-bars; all solutions automatically have each part $\leq 6$ since $7 - 2 = 5 \leq 6$). So prob $= 15/216 = 5/72$.

**When is rerolling $2$ dice optimal?**

Let $a \leq b \leq c$ be the three dice values (sorted). After choosing to reroll, Jason keeps the die with value $a$ (smallest) and rerolls the other two, giving prob $\tfrac{6 - a}{36}$ (where we use $N(7 - a) = 6 - a$ for $1 \leq a \leq 5$; and $0$ for $a = 6$).

Compare to:
- Reroll $1$ die: feasible iff $a + b \leq 6$, prob $1/6$.
- Reroll $3$ dice: prob $5/72$.
- Reroll $0$: prob $1$ iff sum $= 7$.

**Rerolling 2 dominates reroll-1** iff $\tfrac{6-a}{36} > \tfrac{1}{6}$, i.e., $6 - a > 6$, impossible — actually $\tfrac{6-a}{36} \leq \tfrac{5}{36} < \tfrac{6}{36} = \tfrac{1}{6}$. So reroll-$1$ always beats reroll-$2$ **when reroll-$1$ is feasible**, i.e., when $a + b \leq 6$.

So rerolling $2$ is optimal only when reroll-$1$ is infeasible: $a + b \geq 7$.

**Rerolling 2 dominates reroll-3** iff $\tfrac{6 - a}{36} > \tfrac{5}{72}$, i.e., $2(6 - a) > 5$, i.e., $a < 6 - 2.5 = 3.5$, i.e., $a \leq 3$.

**Conditions for reroll-$2$ to be optimal (and sum $\neq 7$):** $a \leq 3$ AND $a + b \geq 7$.

**Enumerate triples $(a, b, c)$ with $a \leq b \leq c$, $a \leq 3$, $a + b \geq 7$.**

- $a = 1$: $b \geq 6$, so $b = 6$. Then $c = 6$. Triple $(1, 6, 6)$. Ordered arrangements: $\tfrac{3!}{2!} = 3$.
- $a = 2$: $b \geq 5$.
  - $b = 5, c \in \{5, 6\}$: $(2, 5, 5)$ — $3$ arrangements; $(2, 5, 6)$ — $6$.
  - $b = 6, c = 6$: $(2, 6, 6)$ — $3$.
- $a = 3$: $b \geq 4$.
  - $b = 4, c \in \{4, 5, 6\}$: $(3, 4, 4)$ — $3$; $(3, 4, 5)$ — $6$; $(3, 4, 6)$ — $6$.
  - $b = 5, c \in \{5, 6\}$: $(3, 5, 5)$ — $3$; $(3, 5, 6)$ — $6$.
  - $b = 6, c = 6$: $(3, 6, 6)$ — $3$.

**Total arrangements.** $3 + (3 + 6 + 3) + (3 + 6 + 6 + 3 + 6 + 3) = 3 + 12 + 27 = 42$.

Exclude cases where the initial sum is $7$: check each triple. None of the listed triples sum to $7$ (e.g., $1+6+6 = 13$, $2+5+5 = 12$, etc.), so all $42$ count.

**Probability.** Total ordered triples: $6^3 = 216$.
$$\text{Probability} = \frac{42}{216} = \frac{7}{36}.$$

The answer is $\boxed{\textbf{(A) } \tfrac{7}{36}}$.

</details>

## Problem 1
*Tags: factoring*

Consider the polynomial $f(x) = ax^3 + bx^2 + cx + d$ where $a, b, c, d$ are non-negative integers satisfying $ab + bc + cd + ad = 20$. Find the sum of all distinct possible values of $f(1)$.

<details><summary>Solution</summary>

**Key observation.** $f(1) = a + b + c + d$. So we need the distinct values of $a + b + c + d$ given the constraint.

**Factor the constraint.** Group the terms of $ab + bc + cd + ad$:
$$ab + bc + cd + ad = b(a+c) + d(a+c) = (a+c)(b+d).$$

So the constraint becomes $(a+c)(b+d) = 20$.

**Introduce new variables.** Let $s = a + c$ and $t = b + d$. Since $a, b, c, d$ are non-negative integers, $s$ and $t$ are non-negative integers with $st = 20$. Also $s, t \ge 0$. But we need $st = 20 > 0$, so both $s \ge 1$ and $t \ge 1$.

**List factor pairs.** The positive integer factor pairs $(s, t)$ of $20$ are:
$$(1, 20), (2, 10), (4, 5), (5, 4), (10, 2), (20, 1).$$

**Are all pairs achievable?** We need to check: for each $(s, t)$, can we find non-negative integers $a, b, c, d$ with $a + c = s$ and $b + d = t$? Yes — e.g., take $a = s,\ c = 0,\ b = t,\ d = 0$.

**Compute $f(1) = s + t$ for each pair.**
- $(1, 20)$ and $(20, 1)$: $f(1) = 21$
- $(2, 10)$ and $(10, 2)$: $f(1) = 12$
- $(4, 5)$ and $(5, 4)$: $f(1) = 9$

**Distinct values:** $\{21, 12, 9\}$. Sum:
$$21 + 12 + 9 = \boxed{42}.$$

</details>

## Problem 2
*Tags: *

_(Problem scrapped from the contest — intended statement: "Let $f$ and $g$ be two polynomials such that $f(g(x)) = g(f(x))$. If $g(x)$ is linear, non-constant, and not identically equal to $x$, and $f(x) = x^3 + 60x^2 + 1000x + c$ for some $c$, find the value of $c$.")_

<details><summary>Solution</summary>

**Setup.** Since $g$ is linear and non-constant, write $g(x) = \alpha x + \beta$ with $\alpha \ne 0$, and $g$ is not the identity means $(\alpha, \beta) \ne (1, 0)$.

**Substituting equality.** $f(g(x)) = g(f(x))$ is
$$(\alpha x + \beta)^3 + 60(\alpha x + \beta)^2 + 1000(\alpha x + \beta) + c = \alpha(x^3 + 60x^2 + 1000x + c) + \beta.$$

**Match leading coefficient.** The $x^3$ coefficient on LHS is $\alpha^3$; on RHS is $\alpha$. So $\alpha^3 = \alpha$, giving $\alpha \in \{1, -1\}$ (since $\alpha \ne 0$).

**Case $\alpha = 1$:** $g(x) = x + \beta$ with $\beta \ne 0$. Then
$$(x+\beta)^3 + 60(x+\beta)^2 + 1000(x+\beta) + c = x^3 + 60x^2 + 1000x + c + \beta.$$
LHS $x^2$ coefficient: $3\beta + 60$. RHS: $60$. So $3\beta = 0$, $\beta = 0$ — contradiction.

**Case $\alpha = -1$:** $g(x) = -x + \beta$. 
$$(-x+\beta)^3 + 60(-x+\beta)^2 + 1000(-x+\beta) + c = -x^3 - 60x^2 - 1000x - c + \beta.$$
LHS: $-x^3 + 3\beta x^2 - 3\beta^2 x + \beta^3 + 60(x^2 - 2\beta x + \beta^2) + 1000(-x+\beta) + c$
$= -x^3 + (3\beta + 60)x^2 + (-3\beta^2 - 120\beta - 1000)x + (\beta^3 + 60\beta^2 + 1000\beta + c)$.

Match to RHS $= -x^3 - 60x^2 - 1000x + (-c + \beta)$:
- $x^2$: $3\beta + 60 = -60 \Rightarrow \beta = -40$.
- $x^1$: $-3\beta^2 - 120\beta - 1000 = -1000$. Check: $-3(1600) - 120(-40) = -4800 + 4800 = 0$ ✓.
- $x^0$: $\beta^3 + 60\beta^2 + 1000\beta + c = -c + \beta$. Compute with $\beta = -40$: $-64000 + 96000 - 40000 + c = -c - 40$, i.e. $-8000 + c = -c - 40 \Rightarrow 2c = 7960 \Rightarrow c = 3980$.

$$\boxed{c = 3980}$$

</details>

## Problem 4
*Tags: trig-identities, dirichlet-kernel*

Compute the number of solutions to
$$1 + \cos(\theta) + \cos(2\theta) + \cos(3\theta) + \cdots + \cos(2024\theta) = \tfrac{1}{2}$$
for $\theta \in [0, 2\pi]$.

<details><summary>Solution</summary>

**Dirichlet kernel identity.** For any integer $n \ge 0$ and $\theta$ with $\sin(\theta/2) \ne 0$,
$$1 + 2\sum_{k=1}^{n} \cos(k\theta) = \frac{\sin\left(\left(n + \tfrac12\right)\theta\right)}{\sin(\theta/2)}.$$

**Why this is true (sketch).** Multiply both sides by $2\sin(\theta/2)$ and use the product-to-sum identity $2\sin(\theta/2)\cos(k\theta) = \sin((k + \tfrac12)\theta) - \sin((k - \tfrac12)\theta)$ — the sum telescopes.

**Apply with $n = 2024$.** The LHS of our equation is $1 + \sum_{k=1}^{2024} \cos(k\theta)$, which is *not* quite the Dirichlet expression (off by a factor of $2$ on the sum). Rearrange:
$$1 + \sum_{k=1}^{2024} \cos(k\theta) = \frac12\left[1 + \left(1 + 2\sum_{k=1}^{2024}\cos(k\theta)\right)\right] = \frac12\left[1 + \frac{\sin(4049\theta/2)}{\sin(\theta/2)}\right].$$

Setting this equal to $\tfrac12$:
$$1 + \frac{\sin(4049\theta/2)}{\sin(\theta/2)} = 1, \quad\text{so}\quad \sin(4049\theta/2) = 0.$$

**Solve.** $\sin(4049\theta/2) = 0$ means $4049\theta/2 = m\pi$ for some integer $m$, i.e. $\theta = \frac{2m\pi}{4049}$.

**Restrict to $\theta \in [0, 2\pi]$.** This gives $0 \le m \le 4049$, so $m \in \{0, 1, \ldots, 4049\}$ — that's $4050$ candidates.

**Exclude spurious solutions.** We divided by $\sin(\theta/2)$, so the identity doesn't apply when $\sin(\theta/2) = 0$, namely $\theta = 0$ or $\theta = 2\pi$. At those $\theta$, the LHS is $1 + 2024 = 2025 \neq 1/2$, so they are not solutions. Remove them: $m \in \{1, 2, \ldots, 4048\}$.

$$\boxed{4048 \text{ solutions}}$$

</details>

## Problem 5
*Tags: symmetric-functions, factoring*

Real numbers $a, b, c$ satisfy
$$\frac{1}{ab} = b + 2c, \qquad \frac{1}{bc} = 2c + 3a, \qquad \frac{1}{ca} = 3a + b.$$
Then $(a + b + c)^3$ can be written as $\frac{m}{n}$ for relatively prime positive integers $m, n$. Find $m + n$.

<details><summary>Solution</summary>

**Clear denominators.** Multiply each equation by $abc$:
$$c \cdot (b + 2c) \cdot b \cdot a = abc \cdot (b+2c) = abc \cdot \frac{1}{ab} = c.$$
Wait, let's redo that carefully. From $\frac{1}{ab} = b + 2c$, multiply by $ab$: $1 = ab(b+2c) = ab^2 + 2abc$. Similarly for the others:
$$1 = ab^2 + 2abc, \quad 1 = 2bc^2 + 3abc, \quad 1 = 3a^2c + abc. \quad (\star)$$

**Try a symmetry ansatz.** The equations aren't symmetric in $a,b,c$ (the coefficients $1, 2, 3$ break symmetry), so a single solution to this system likely has fixed ratios between $a, b, c$. Suppose $a = tc$ and $b = uc$ for some constants $t, u$.

**Substitute.** Equation 1: $1 = ab^2 + 2abc$ becomes $1 = tc \cdot u^2c^2 + 2 \cdot tc \cdot uc \cdot c = tu^2 c^3 + 2tu c^3 = tu c^3 (u + 2)$.

Similarly equations 2 and 3 after substitution (dividing out $c^3$):
- Eq 1: $tu(u+2) c^3 = 1$
- Eq 2: $2u(u + 3t) c^3 = 1 $... let me recompute. $1 = 2bc^2 + 3abc = 2uc \cdot c^2 + 3 \cdot tc \cdot uc \cdot c = 2u c^3 + 3tu c^3 = u c^3 (2 + 3t)$.
- Eq 3: $1 = 3a^2c + abc = 3t^2c^2 \cdot c + tc \cdot uc \cdot c = 3t^2 c^3 + tu c^3 = tc^3(3t + u)$.

So dividing out $c^3 \ne 0$:
$$tu(u+2) = u(2 + 3t) = t(3t + u) \cdot \frac{1}{c^3}^{-1}.$$

Hmm wait — all three equal $1/c^3$. Set $K = 1/c^3$ for convenience. Then:
- (I) $tu(u+2) = K$
- (II) $u(2 + 3t) = K$
- (III) $t(3t + u) = K$

Setting (I) = (II): $tu(u+2) = u(2+3t)$. If $u \ne 0$: $t(u+2) = 2 + 3t \Rightarrow tu + 2t = 2 + 3t \Rightarrow tu = 2 + t \Rightarrow t(u - 1) = 2$.

Setting (II) = (III): $u(2 + 3t) = t(3t + u) \Rightarrow 2u + 3tu = 3t^2 + tu \Rightarrow 2u + 2tu = 3t^2 \Rightarrow 2u(1 + t) = 3t^2$.

**Reduce to one unknown.** From $t(u-1) = 2$: $t = 2/(u-1)$, assuming $u \ne 1$.

Substitute into $2u(1+t) = 3t^2$:
$$2u\left(1 + \frac{2}{u-1}\right) = 3 \cdot \frac{4}{(u-1)^2}.$$
$$2u \cdot \frac{u-1+2}{u-1} = \frac{12}{(u-1)^2}.$$
$$\frac{2u(u+1)}{u-1} = \frac{12}{(u-1)^2}.$$
$$2u(u+1)(u-1) = 12.$$
$$u(u^2 - 1) = 6, \quad u^3 - u - 6 = 0.$$

**Solve the cubic.** Try $u = 2$: $8 - 2 - 6 = 0$ ✓. Factor: $u^3 - u - 6 = (u-2)(u^2 + 2u + 3)$. The quadratic has discriminant $4 - 12 < 0$, so no other real roots. Thus $u = 2$.

Then $t = 2/(u-1) = 2$. So $a = 2c$ and $b = 2c$.

**Solve for $c$.** Plug into the original first equation: $\frac{1}{ab} = b + 2c$ becomes $\frac{1}{(2c)(2c)} = 2c + 2c = 4c$, i.e., $\frac{1}{4c^2} = 4c$, giving $16c^3 = 1$, so $c^3 = 1/16$.

**Compute $(a+b+c)^3$.** $a + b + c = 2c + 2c + c = 5c$, so $(a+b+c)^3 = 125 c^3 = 125/16$.

With $m = 125$, $n = 16$, $\gcd(125, 16) = 1$ (coprime ✓).

$$\boxed{m + n = 141}$$

</details>

## Problem 6
*Tags: vietas-formulas, recurrence-relations, symmetric-functions*

Let $\{a_n\}_{n=0}^\infty$ satisfy $a_{n+3} = 2a_{n+2} - 23a_{n+1} + 3a_n$ with $a_0 = 20,\ a_1 = 0,\ a_2 = 23$. Let $b_n = a_n^3$. There is a unique positive integer $k$ and constants $c_0, \ldots, c_{k-1}$ with $c_0 \ne 0$ and $c_{k-1} \ne 0$ such that for all sufficiently large $n$,
$$b_{n+k} = \sum_{t=0}^{k-1} c_t\, b_{n+t}.$$
Find $k + \sqrt{|c_{k-1}|} + \sqrt{|c_0|}$.

<details><summary>Solution</summary>

**Setup: characteristic polynomial.** The recurrence $a_{n+3} = 2a_{n+2} - 23a_{n+1} + 3a_n$ has characteristic polynomial $x^3 - 2x^2 + 23x - 3$. Call its roots $r, s, t$. Then by standard theory,
$$a_n = A r^n + B s^n + C t^n$$
for some constants $A, B, C$ determined by initial conditions.

**Cube it.** $b_n = a_n^3 = (Ar^n + Bs^n + Ct^n)^3$. Expanding by the multinomial theorem:
$$b_n = \sum_{\substack{i + j + k = 3 \\ i, j, k \ge 0}} \binom{3}{i, j, k} A^i B^j C^k \, (r^i s^j t^k)^n.$$

Each non-zero term contributes an exponential of the form $\mu^n$ where $\mu = r^i s^j t^k$. The number of distinct multi-indices $(i, j, k)$ with $i+j+k = 3$, $i,j,k \ge 0$ is $\binom{5}{2} = 10$. (Generically these give $10$ distinct $\mu$'s.)

**Order of the recurrence for $b_n$.** If the $10$ products $\mu_\alpha = r^i s^j t^k$ are distinct, $b_n$ satisfies a linear recurrence with characteristic polynomial $\prod_\alpha (x - \mu_\alpha)$, which has degree $10$. So $k = 10$.

**Find $c_0$ via product of roots.** The recurrence $b_{n+k} = \sum_t c_t b_{n+t}$ has characteristic polynomial $x^k - c_{k-1} x^{k-1} - \cdots - c_1 x - c_0$. By Vieta's on this polynomial:
$$\prod_\alpha \mu_\alpha = (-1)^k \cdot (\text{constant term}) = (-1)^{10} \cdot (-c_0) = -c_0.$$

Now compute the product of all $\mu_\alpha$. Each $\mu$ is $r^i s^j t^k$. Summed over the $10$ multi-indices, the total exponent of $r$ is $\sum i$. By symmetry (the roles of $r, s, t$ are symmetric in the multi-index enumeration), $\sum i = \sum j = \sum k$ for $(i,j,k)$ running over all solutions to $i+j+k=3$. The grand total is $\sum (i+j+k) = 10 \cdot 3 = 30$, so each of $\sum i, \sum j, \sum k$ equals $10$. Therefore:
$$\prod_\alpha \mu_\alpha = r^{10} s^{10} t^{10} = (rst)^{10}.$$

From $x^3 - 2x^2 + 23x - 3$, Vieta gives $rst = 3$ (product of roots = $-$ constant / leading = $3$). So $\prod \mu_\alpha = 3^{10} = 59049$, and $c_0 = -59049$. Then $|c_0| = 3^{10}$ and $\sqrt{|c_0|} = 3^5 = 243$.

**Find $c_{k-1}$ via sum of roots.** By Vieta, sum of roots $= c_{k-1}$ (coefficient of $x^{k-1}$ flipped sign).
$$\sum_\alpha \mu_\alpha = \sum_{i+j+k=3} r^i s^j t^k = h_3(r, s, t),$$
the $3$rd **complete homogeneous symmetric polynomial**. Using Newton's-type identity or direct expansion:
$$h_3 = \sum r^3 + \sum_{\text{unordered distinct pairs}} r^2 s + rst_{\cdot}$$

Break into three types:
- Cubes ($r^3, s^3, t^3$): sum $= p_3$, the $3$rd power sum.
- Mixed $r^i s^j$ with one of them squared ($r^2 s, r s^2, r^2 t, rt^2, s^2 t, s t^2$): sum $= p_1 p_2 - p_3$ (using $(r+s+t)(r^2 + s^2 + t^2)$ and subtracting the pure cubes).
- All three distinct, $rst$: sum = $e_3$.

So $h_3 = p_3 + (p_1 p_2 - p_3) + e_3 = p_1 p_2 + e_3$.

Compute power sums from Vieta: $e_1 = r+s+t = 2$, $e_2 = rs+rt+st = 23$, $e_3 = 3$.
- $p_1 = e_1 = 2$.
- $p_2 = e_1^2 - 2 e_2 = 4 - 46 = -42$.

Therefore $h_3 = 2 \cdot (-42) + 3 = -81$. So $c_{k-1} = -81$, giving $\sqrt{|c_{k-1}|} = \sqrt{81} = 9$.

**Answer.**
$$k + \sqrt{|c_{k-1}|} + \sqrt{|c_0|} = 10 + 9 + 243 = \boxed{262}.$$

</details>

$$S = \sum_{n=1}^\infty \arctan\!\left(\frac{1}{F_n}\right) \arctan\!\left(\frac{1}{F_{n+1}}\right).$$
Find $\lfloor 80 S \rfloor$. (Hint: $\arctan(1/1) = \arctan(1/2) + \arctan(1/3)$.)

<details><summary>Solution</summary>

_Short hint: The hint generalizes to $\arctan(1/F_{2k}) = \arctan(1/F_{2k+1}) + \arctan(1/F_{2k+2})$, provable via the tangent-difference formula and Cassini's identity $F_{2k} F_{2k+2} - F_{2k+1}^2 = -1$. Using this to rewrite $\arctan(1/F_{2k+1}) = \arctan(1/F_{2k}) - \arctan(1/F_{2k+2})$ creates telescoping in the product sum. Full beginner-friendly write-up to come._

_Short hint: The double product over $(i, j)$ with $\gcd(i, n) = 1$ and $\gcd(j, n) \ne 1$ equals $\prod_i \Phi_{n / \gcd(j, n)}$-style resultants.
